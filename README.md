# MarketMirror

三类 Agent · 市场情景仿真 · 可追溯决策

MarketMirror 是本地运行的金融情景实验平台。输入政策、宏观消息或公司回复，设置情景和策略参数，比较激进型、保守型、机构型的目标仓位、订单、成交与账户路径。

[平台使用说明](design/README.md) · [研究操作与复现](research/README.md) · [系统架构](RESEARCH_REBUILD_PLAN.md)

## 快速启动

需要 Python 3.10+。在 PowerShell 执行：

```powershell
git clone --branch codex/research-rebuild https://github.com/rain-lei/MarketMirror.git
cd MarketMirror
python -m pip install -r requirements-research.txt
.\scripts\start-platform.ps1
```

打开 [本机平台](http://127.0.0.1:8770/)。服务在终端前台运行，按 `Ctrl+C` 停止；更新代码后重启服务并刷新页面。无需前端构建。合成实验无需原始 Excel、历史归档或模型密钥。

启动脚本会从项目 `.venv`、已激活环境、PATH 和 Conda 基础环境选择满足依赖的 Python，并显示实际路径。可用 `-Python "C:\path\to\python.exe"` 指定解释器。其他系统可执行：

```sh
python -B -X utf8 -m design.server --port 8770
```

## 平台能做什么

| 入口 | 用途 |
| --- | --- |
| 实验空间 | 新建、运行、读取和复制本机实验；恢复草稿与失败运行 |
| 策略配置 | 编辑三类参数，用同一账户状态比较有消息与无消息的决策 |
| 结果分析 | 回放各资产与步骤，查看判断分值、目标仓位、订单、实际成交和组合风险 |
| 实验比较 | 核对两份实验的条件与参数，比较收益、回撤、费用、成交及超限，导出固定版本报告 |
| 批量对照 | 按多个种子运行固定情景；失败项单列，继续其他项并支持重试 |
| 真实原文案例 | 读取六个归档开发案例，对照无文本、关键词、复核 LLM 与资产暴露置换 |
| 历史行情实验 | 读取真实公司回复与历史收益实验，展示三类决策及文本依据 |

三类 Agent 共用参数化规则引擎，差异来自敏感度、风险预算、确认和再平衡规则。它们没有分别训练成三个投资者模型，也不要求每一步都做出不同动作。

DeepSeek 用于提取原文事实和逐字引文。仓位、订单和成交由本地引擎计算。新建实验的信号、不确定性和时长由用户设定；研究案例使用登记的事实映射。目标改变可能被确认、风险、资金、整手和撮合约束阻止，不一定产生交易。

## 使用流程

1. 输入原文和发布时间，可选提取事实并检查引用。
2. 设置信号、不确定性、消息范围、市场偏移、波动率下限、种子及策略参数。
3. 运行有消息与无消息两组，读取逐步账本和同一步决策对照。
4. 如需调整参数，复制实验后再运行，在实验比较页核对条件和结果。
5. 下载配置、文本依据、账本及报告。

同一标签页会保存草稿和所选实验。模型关联、参数与成功结果均有独立快照；修改默认配置不会改写已存档实验。样例消息只用于复用原文，不提供预制收益或成交结果。

## 文本分析配置

在项目根目录创建 `.env.local`：

```dotenv
MARKETMIRROR_LLM_API_KEY=your_api_key
```

后端读取本机凭据，使用 `http://aigw.dlut.edu.cn/v1` 和 `DeepSeek-V4-Flash-0731-W8A8`。密钥不返回浏览器，配置文件不提交到 Git。模型设置页可查看配置；点击“检测连接”使用固定合成文字验证请求和引文结构。输入消息时点击“提取事实”才分析该原文。

## 数据与结论边界

实验及分析保存在 Git 忽略的 `research_outputs/platform_workspace/`。六个原文案例和历史行情实验依赖额外的本地归档；新克隆缺少归档时会明确提示。恢复与重算入口见[研究复现说明](research/PROTOTYPE_REPRODUCTION_2026.md)。

新建和批量实验是三资产合成市场。消息从第 5 步进入，价格会受模型内交易反馈影响。历史行情实验使用已实现收益，Agent 不改变历史价格。两种路径都用于规则解释和受控对照，尚未证明真实投资者行为、市场预测或可交易收益。

[真实原文链路](research/SOURCE_TEXT_TO_AGENT_DECISIONS_2026.md)和[真实历史收益实验](research/REAL_OBSERVED_EXPERIMENT_20261006.md)记录了已实施的实验，包括负结果。结构校验、引用匹配和账本审计各有明确范围，不等同于语义准确率或实证效果。

平台仅监听本机，提供个人研究工作区；多用户认证、权限和部署管理尚未实现。

## 验证与目录

安装支持 `node --test` 的 Node.js 后执行：

```powershell
.\scripts\verify-platform.ps1
```

脚本运行平台 Python/Node 回归和 JavaScript 语法检查；存在本地归档时核验原文路径与历史决策，缺少归档时明确跳过。研究全套测试与命令见[研究操作说明](research/README.md)。测试通过不代替实际浏览器验收。

```text
design/            平台界面、服务、实验存储与仿真适配
research/          数据管道、语义处理、决策与市场引擎、实验报告
scripts/           启动和平台验证脚本
tests/             平台与研究回归
research_outputs/  本地数据与运行产物（Git 忽略）
```
