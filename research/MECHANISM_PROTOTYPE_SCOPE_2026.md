# 三类 Agent 机制研究范围

研究目标是在明确的信息与交易约束下，解释三类预设决策规则的仓位、等待、下单与成交，并通过对照和归档重放核验结果。可视化平台提供实验操作、逐步账本、条件比较和证据导出，操作见[平台说明](../design/README.md)。

## 研究问题

1. 相同账户状态和可见信息下，激进、保守、机构三类规则如何形成不同或相同的目标与交易节奏？
2. 文本在哪个环节改变行为？直接信息作用、前期账户资源和后续价格反馈怎样分别核对？
3. 不确定性、流动性与共同冲击增强时，哪些机制产生等待、减仓或未成交？结果对种子及预设参数网格是否敏感？

角色是行为假设，没有从真实投资者数据识别出三个模型。机构型不预设收益更高，三类也不强制产生不同动作。多个账户和种子是模型内观察，不能替代真实主体和独立事件。

## 输入与证据

原文、逐字引文、来源可见时间、模型原答及助手复核分别存档。方向、幅度、期限和资产暴露不能从文字中识别时，保留未知或明确登记情景假设。公司提问里的推测不替代已确认回复，财务字段须有单位、期间及披露时点证据。

归档六来源研究是已查看且经修订的开发案例，不能当作未经干预的抽取准确率。原武汉 v6 类别宏 F1 为 0.561，低于既定 0.60；六案例的可解释链路不改变该正式自动信号门槛。详见[独立评估](WUHAN_INDEPENDENT_EVALUATION_V6.md)。

## 验收合同

| 内容 | 必须保存与核对 |
| --- | --- |
| 决策 | 信号、分值、风险预算、确认/再平衡、目标、请求、接受与实际成交 |
| 时点 | 原文公开代理、特征截点、执行参考及决策步；禁止未来输入 |
| 对照 | 固定来源、参数和种子；无文本、关键词、复核 LLM 与暴露置换分开 |
| 账务 | 现金、股份、费用、库存和账户汇总；未成交、裁剪、失败和超限如实记录 |
| 敏感性 | 所有预定种子、强度、时长和资源条件，保留负结果与零效应 |
| 复现 | 配置、数据、代码、模型回答和产物哈希；独立目录重算与固定归档读取 |
| 界面 | 实际流程和视觉检查；不把状态测试当作浏览器验收 |

收益、波动、停滞、集中度和回撤用于异常检查及描述，不以逐日拟合真实行情为验收目标。真实市场预测、投资者参数识别和监管效果另需实证设计与数据。

登记范围的研究结果见[机制总结](RESEARCH_SUMMARY_2026.md)、[证据核对](PROTOTYPE_ACCEPTANCE_2026.md)、[离线复现](PROTOTYPE_REPRODUCTION_2026.md)及[资源全量结果](TEMPORAL_RESOURCE_UNIT_RESULTS_2022.md)。改动样本、抽取任务或类别体系须登记新版本；已查看样本不能重新包装成留出验证。
