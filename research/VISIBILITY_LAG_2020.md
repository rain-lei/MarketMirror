# 2020 年问答可见时间延迟敏感性

文本预测基线把来源问答时间作为公开可见时间代理，缺少平台首次公开日志。本实验固定原三只股票、行情、678 行面板、177 条测试预测、训练/验证/测试切分和 Ridge 选参方式，分别把每条提问及回复的来源可用时间额外后移 0、1、3、7 个**自然日**。四个延迟是解释风险用的假设网格，不是测得的发布时间，也不是按测试结果调参。

0 日重新建表和评价与原固定运行逐项一致；四个情景的纯行情模型和测试预测完全相同。原始敏感性运行通过固定清单的输入、代码及输出哈希核验；在另一个目录从输入独立重跑后，结果、报告和运行清单均逐字节一致。逐行数据不进入 Git，只有规则、清单和本说明受版本控制。

MAE 和差值均以收益率**百分点**表示。区间沿用原实验的 5 交易日循环区块重抽样，只是本固定测试集上的近似诊断；四个区间都包含零。随着假设延迟变长，文本的点估计优势消失，但这既不能确定真实发布延迟，也不能说明某个延迟值更合理。原始问答时间、修订记录、行情历史版本和样本选择仍待外部核实。

完整本地结果在 `research_outputs/text_pilot_2020/visibility_lag_v2/`，独立重跑在 `research_outputs/text_pilot_2020/visibility_lag_verified_rerun_v1/`。从仓库根目录运行（需要已存档的原始数据和基线产物，目标目录须为空）：

```powershell
python -m research.baselines.visibility_lag research/configs/visibility_lag_2020.json --output-dir research_outputs/text_pilot_2020/<新的运行目录>
python -m research.registry.verify_catalog research/configs/integrity_catalog_visibility_lag_2020.json --output-dir research_outputs/<新的核验目录>
```

该实验仍是探索性小样本测试；不包含 LLM 信号或 Agent 决策，也不证明可交易收益、监管预警或事件因果效应。
