# 2018 资管新规：三家试点发行人政策前暴露映射

为把官方政策材料和公司资料连接起来，先对 2018 事件研究里已有的三家试点股票做有限主体核验。范围只到“是否属于政策直接监管的金融机构/银行资管业务”，不推断政策对股票收益的符号或大小。

| 证券 | 政策前公司证据 | 直接机构范围 | 处理 |
|---|---|---|---|
| 000001 平安银行 | 2018 年一季报载明银行主体；银行官网 2018-01-29 发布一项 2017 年理财产品年度管理报告，报告说明该银行管理的产品于 2017-03-13 成立 | 匹配。央行意见适用于银行资产管理业务；资料表明政策前存在银行理财产品管理活动 | 直接监管机构/业务类型匹配；股价方向与影响幅度未知 |
| 000002 万科 | 2017 年第三季度报告载明证券代码，并披露房地产业务 | 不匹配。发行人本身不是金融机构 | 可能有融资渠道的间接传导，具体暴露未量化 |
| 600519 贵州茅台 | 2017 年年报摘要载明证券代码，描述白酒生产、销售和行业情况 | 不匹配。披露的业务与金融机构资管业务无直接类型匹配 | 一般市场或融资传导未量化 |

公司证据来自政策发布前的文件：[平安银行 2018 年一季报](http://static.cninfo.com.cn/finalpage/2018-04-20/1204670574.PDF)、[平安银行理财产品 2017 年度报告页面](https://bank.pingan.com/touzilicai/1517190391679.shtml)、[万科 2017 年第三季度报告](https://www.vanke.com/upload/file/2017-10-27/dddb60a1-b71c-49d6-b63a-44cc2aa546ae.PDF)和[贵州茅台 2017 年年报摘要](http://static.cninfo.com.cn/finalpage/2018-03-28/1204526772.PDF)。央行政策原文说明其直接规制金融机构资管业务，并讨论银行理财产品、信托及证券、基金、期货和保险资管产品等范围；[事件来源及时点核验](POLICY_EVENT_CONTEXT_CATALOG_2018_2020.md)已保留原文哈希。

万科和贵州茅台“没有直接机构范围匹配”不代表没有市场影响。比如房地产公司的融资可能通过银行和资管产品传导，但本试点没有资金来源构成或暴露比例证据。它们也没有标准行业代码：目录只保留政策前披露中的业务描述，不将自由文本伪装成标准分类。

证券代码与简称由 BaoStock 当前回取的证券基础资料交叉匹配，回取时间为 2026-09-28。它只作事后身份交叉表，**没有作为 2018 年 Agent 特征**；公司业务判断使用政策前正式披露。公司文件通过 Firecrawl 抽取的本机 Markdown 保存于忽略目录 `.firecrawl/`，目录中的哈希验证的是抓取文本，不是原始 PDF 字节。万科和贵州茅台日期取自官方归档路径；两份正文只精确到文件报告期/月份，因此没有声称精确首次公开时刻。央行政策后发，不作为公司政策前输入，只用于界定事件适用范围。

该映射的边界很窄：只有 3 家已经研究过的股票，不能代表上市金融机构或整个 126/123 家公司队列；银行机构类型匹配也不意味着银行全部业务、全部资产或股价受到同方向影响。三条记录均将冲击方向和幅度设为 `unknown`，没有启用 Agent 信号，也没有用本试点调参后再宣称独立验证。

机器可校验目录为 [`configs/issuer_exposure_asset_management_2018_pilot.json`](configs/issuer_exposure_asset_management_2018_pilot.json)，结构合同为 [`data_contracts/issuer_event_exposure.schema.json`](data_contracts/issuer_event_exposure.schema.json)，核验器为 [`data_pipeline/issuer_event_exposure.py`](data_pipeline/issuer_event_exposure.py)。重验命令：

```powershell
python -m research.data_pipeline.issuer_event_exposure
python -m unittest tests.test_issuer_event_exposure -v
```

2026-09-30 本地复核时，来源归档及政策原文哈希均通过；三家中 1 家直接范围匹配，Agent 信号仍为 0。完整测试套件 `python -m unittest discover -s tests -q` 为 330/330 通过。映射仍是三股方法试点，不足以解释全市场或证明预测改善。

后续优先补齐政策前可得的标准行业分类和更大公司队列的直接暴露证据，再预先固定“无文本、问答、政策/行业暴露、组合输入”消融。异常成交额目前只显示混合的小幅预测变化；应优先验证它与政策暴露、市场状态和流动性限制的交互是否稳定，并继续把手设的冲击系数与可观察风险指标分开。任何新因素只有在严格时点、冻结样本和独立验证下改善基线，才考虑接入 Agent。
