# 真实统一库的事前特征隔离核验

**两个既有截止时点的特征 CSV 均只含受限白名单中的问答计数、长度与字面关键词指标；财务快照、来源 `季度` 和回复后的文本没有进入这些导出。** 这是对实际统一数据库和已归档产物的核验，补充了此前只在合成样本上做的时间隔离单元测试。

| 特征截止时点（中国时间） | 公司 | 截点内提问 | 截点内可见回复 | 输出列 | 全新导出与归档 |
|---|---:|---:|---:|---:|---|
| 2020-01-23 23:59:59 | 2,601 | 21,070 | 15,435 | 37 | CSV 逐字节一致 |
| 2026-04-01 00:00:00 | 1,439 | 32,035 | 24,435 | 37 | CSV 逐字节一致 |

[审计程序](data_pipeline/audit_asof_feature_isolation.py)先核对统一数据库、特征政策、两份原 CSV 和导出清单的 SHA-256；限制政策输入为公司代码、提问/回复时间及文本，并要求财务、来源季度、`p`、`p/e`、最终回复状态和用户身份继续列在排除项。对两个窗口，程序直接从 `qa_record` 以 `question_available_at <= as_of` 和 `reply_eligible=1 AND reply_available_at <= as_of` 分组查询，再逐公司核对 CSV 的提问数、已知回复数、尚无可见回复数与比例。最后在临时目录用现行导出器重建两份 CSV，比较 SHA-256。没有复制或保留问答原文；审计 JSON 只保存聚合计数和哈希，位于 Git 忽略的 `research_outputs/unified/asof_feature_isolation_audit_v1.json`。运行 `python -m research.data_pipeline.audit_asof_feature_isolation --audit-existing` 可从源库重算。

统一数据库中的 **12,287 份财务快照**仍全为 `unverified`，报告期和公开时间为空。已归纳出的来源[回复日期分桶规则](FINANCIAL_QUARTER_ASSIGNMENT_AUDIT_2026.md)没有改变这一状态。此次核验表明**当前两个文本特征导出**没有把它们当作事前变量；它不证明来源时间就是首次公开时间，也不涵盖所有语义 Agent 入口或模型预测表现。财务字段继续留在隔离层，待提供方给出报告期、单位、变换和公开时点后才能另建合规的按时点财务特征。
