- 当前共 68 项测试通过，覆盖财务提取、事件窗口、问答追溯、按时点导出、提供方异常数据、证据缓存、文本预测时间隔离、合成 Agent 账本、语义标注隔离、成交活动单位/交易日核验及日期对照隔离。

## 统一数据集和时点规则

- `qa_id` 按文件内容哈希、工作表和 Excel 行号建立；多来源的相同行号不会冲突。
- 公司主表按来源股票代码建立；交易所和法定主体身份尚未核实。简称分别保存为带来源的别名。
- 390,608 条历史问答逐行关联到待核对财务快照，不复制财务值作为预测特征。
- 内容指纹发现 48 条额外重复记录，涉及 41 个重复组；保留全部来源行，不自动去重。
- 2020 年的回复只有日期。使用次日零点作为保守可用时点，并保留原始日期和专用质量标记；没有推定真实日内发布时间。
- 问答来源时间暂作公开可见时间代理，缺少发布时间日志和修订历史，正式预测验证前还需确认。
- 特征导出只使用截止时刻内的提问及已知回复，统计数量、文本长度和字面关键词。排除财务、标签、来源季度、用户信息和最终回复状态统计。
- 运行清单保存输入、处理代码、规则和数据库哈希；特征导出另有时窗、列清单、数据和代码哈希。

## 行情与事件研究流程

- 股票和基准可以分别输入价格或简单收益率；单位、复权与基准口径必须明确，输出统一为小数收益率。
- 使用独立的交易日历校验覆盖范围。缺失日或重复日期会报错，不补价格，不把停牌跨日价格变化当作单日收益。
- 行情清单保留配置、数据来源、代码和输出哈希，以及日历、每只股票的输入和收益覆盖范围。
- 事件要求提供来源证据。只有日期时从次日开始视为可见；带时区的公告时间按北京时间 15:00 收盘假设对齐，实际事件日取之后可用的交易日。
- 每次股票/事件组合保留完整估计窗口、alpha、beta、逐日异常收益和 CAR。窗口不足等失败会单独记录，不替换为零值。
- 有预选股票失败时，不报告该事件的完整样本平均 CAR；CLI 返回非零退出码。
- 没有显著性、置信区间或因果识别。估计窗口包含其他冲击时会污染模型拟合，仍需研究设计处理。

## 首次真实行情事件研究

已完成 2019-06-01 至 2020-12-31 的 BaoStock 数据下载。预选代码为 `sz.000001`、`sz.000002`、`sh.600519`，基准为 `sh.000300`；共有 388 个开市日和 1,161 条标准股票收益观测。

全年的后复权价格中发现 4 个相邻价格断点，原始价格保留在核查层。股票输入使用提供方逐日涨跌幅，与同日收盘和参考前收盘逐条核对通过；没有修补价格，也没有改用缩短的全年数据。

武汉通告采用日期保守和生效时间上界代理两种对齐，分别对齐到 2020-02-03 和 2020-01-23；同一事件的 6 个股票/口径组合计算通过。万科的 CAR 符号随对齐口径变化，说明事件定义和窗口选择需要敏感性验证。

提供方文档、新华社事件报道和上交所休市公告已缓存并保存哈希；运行前后校验。本次没有证明因果、统计显著性或预测能力，价格版本也不是历史时点归档版。

进一步按同样的市场模型和窗口逐日计算其他候选日期，剔除估计期或事件窗口触及真实事件窗口的日期。2019-12-01 至 2020-12-31 范围内保留事前 23 日（2019-12-10 至 2020-01-10）、事后 88 日（2020-08-17 至 2020-12-24）；其余有 143 日与隔离区间交叉、11 日窗口或拟合不完整。平安银行在日期保守口径的实际绝对 CAR 处于事前候选值的 87.0% 以上、事后候选值的 53.4% 以上；等权三股均值分别仅为 8.7% 和 9.1%。各股票和两种口径完整列表见 `research_outputs/observed_2020/placebo/placebo_report.md`。候选窗口重叠且前后市场环境不同，排名不构成 p 值、有效随机化检验或预测验证。

详细解释见 `OBSERVED_PILOT_2020.md`。实际产物在 `research_outputs/observed_2020/`，包括下载、证据、标准行情、实验结果和科学图。

## 文本增量预测初步对照

原事件股票中的 `000002` 和 `600519` 在 2020 问答来源内没有记录，因此另行固定有记录的 `000001`、`000063`、`002594` 做预测对照；这属于查看来源后的探索性选股，尚未外部预注册。三只股票在训练开始前已有问答记录，构建器检查这一条件。公开行情仍由 BaoStock 取得；30 日问答特征只读取 2020 来源，不将来源覆盖范围外的缺失视为零。目标是收盘后预测下一交易日收益，且只在目标收益已知时用作训练标签。测试模型参数在首个测试截止时刻前冻结。

测试集为 2020-10-09 至 2020-12-30 的 59 个交易日，每只股票 59 条，共 177 条。行情 Ridge 的 MAE 为 2.1591 个收益率百分点；行情加文本为 2.1397，差值约 -0.0194 个百分点。按交易日配对并做五日循环区块重抽样的近似 95% 区间为 [-0.0461, +0.0026] 个百分点，包含零。文本增益未被确认；各股票结果及局限见 `research_outputs/text_pilot_2020/results/prediction_report.md`，输入和代码哈希见同目录 `prediction_manifest.json`。该结果不能用于 Agent 行为参数校准。

## Agent 机制合成验证

三类 Agent 共用现金、份额、目标仓位和风险预算规则，示意参数写在 `configs/synthetic_stress_v1.json`。16 步合成冲击的启用文本组中，激进型交易 9 次、保守型 8 次、机构型 6 次；成交额分别约为 17.87 万、8.00 万、8.92 万示意货币单位。对应的无文本信号对照也已生成。每步总现金、份额和手续费守恒，且执行成交额受流动性上限约束；完整日志和输入/代码哈希在 `research_outputs/synthetic_stress_v1/`。

本阶段只验证规则、限制和行为可区分性。角色参数、合成信号、流动性及价格冲击均未用真实交易记录校准，不能据此推断哪类现实投资者会这样交易，也不能解释为已完成历史市场仿真。

## 语义信号标注准备

已从指定 2020 年来源中按可见时间、公司级分组与八个字面话题层抽取 128 条本地待标注材料；提问和回复各 64 条，涉及 123 家公司。提问条目不包含未来回复，回复条目只在回复可用后出现。原文和空白标签留在 Git 忽略的 `research_outputs/semantic_annotation_pilot_2020/`，清单记录原始来源、统一库、配置、代码及输出哈希。标注说明见 `semantic/ANNOTATION_GUIDE.md`。

## 历史成交活动初测

BaoStock 已留存的原始逐日响应含成交股数和人民币成交额，单位与已缓存的官方 API 文档核对。对 `000001`、`000002`、`600519` 的 388 个开市日共 1,164 条记录执行来源文件哈希、日历、代码、复权/交易状态及数值检查，输出在 `research_outputs/observed_2020/activity/`。没有用断点异常的后复权价格解释成交额。

原事件研究的 6 个股票/口径组合按各自窗口以前的 120 日成交中位数计算逐日倍数，共 54 条，输出在 `research_outputs/observed_2020/activity_event/`。按 2020-02-03 对齐时，三只股票当日成交额分别为基期中位数的 2.278、3.060、3.753 倍；按 2020-01-23 生效时间上界代理对齐时分别为 1.251、2.159、1.719 倍。PNG/SVG 对照图在 `activity_figures/`，已目视检查；右图相对日 +1 与左图相对日 0 是同一个 2020-02-03。同一武汉事件的两个口径不能视作独立事件。成交额是双向总成交，不包含买卖净方向、投资者类型或可执行深度，不能据此校准价格冲击或断言因果。

## 下一轮实施顺序

1. 获取可观察交易/持仓或参与者类别证据、盘口深度与净订单流，再决定三类 Agent 和价格冲击的可校准目标；保留无文本消融和简单规则对照。
2. 扩大并外部预注册样本及事件，检查其他冲击、价格版本、公开时刻与样本选择，补充跨期统计检验。
3. 对本地语义样本独立双人标注并裁定，再固定模型/提示、运行留出抽取评估；通过后才可考虑将真实信号接入 Agent。

数据口径没有得到确认前，财务快照不用于杠杆率、资产收益率等计算，也不作为已验证预测输入。
