# 非问答政策事件目录：来源、时点与适用范围

已将现有政策材料整理为结构化目录，作为后续宏观政策和市场日历输入的来源底座。当前包含 2018 年资管新规、2020 年武汉交通管制通告、2020 年上交所春节休市延长公告。目录保留原始来源类别、归档路径和 SHA-256，并将**发布时间、可见时点规则、措施生效期、直接适用范围**分别记录。

三条记录的时间口径并不相同：

| 事件 | 来源与精度 | 可见性处理 | 生效/适用范围 |
|---|---|---|---|
| 资管新规，2018-04-27 | 央行官方原文；页面正文给出 18:38:49 | 精确页面时间按交易日历映射，属于收盘后发布时间；不声称是所有渠道首次公开时刻 | 面向金融机构；上市公司和行业映射未完成；没有把发布日期误作单一实施日期 |
| 武汉交通管制，2020-01-23 | 新华社保存通告全文；页面显示 03:15:55。武汉市生态环境局后续回顾称发令约在凌晨 2 时 | 页面刊发时间可精确核验；约略发令时间不等于精确网页时间，两者都不证明全渠道首次公开；10:00 是措施生效时间 | 从 10:00 起暂停市内公共交通并关闭离汉通道；公司暴露未映射 |
| 上交所延长休市，2020-01-27 | 上交所公告；有日期、无核实的日内时刻 | 按发布日期和实际交易日历处理 | 休市延至 2 月 2 日、2 月 3 日开市；记录为交易日历事件，不当作统一股票收益冲击 |

三类目录来源归档均与声明的 SHA-256 一致。央行网页归档同时含历史 `PubDate`/正文发布时间和后续网页 `createDate`，目录使用正文中的历史发布时间，并在备注中限制其解释。武汉第 1 号通告的城市政府原始网页当前无法访问；目录使用新华社全文页的可验证页面时间，并另存武汉市生态环境局关于“凌晨 2 时许”发令的后续回顾，明确两种时间含义不同。上交所记录仅覆盖该交易所公告直接证明的内容。

这些事件现在都是 `context_only`，`agent_signal_enabled=false`。武汉页面时间增加了同一通告的第三套日频时点敏感性，结果见[事件可见时点对齐审计](EVENT_VISIBILITY_ALIGNMENT_2018_2020.md)。已单独对 2018 事件研究中的三家试点公司做政策前主体核对：平安银行符合银行资产管理机构类型，万科和贵州茅台没有直接机构范围匹配；完整上市公司样本和标准行业代码仍未映射。详见[发行人暴露试点](ISSUER_POLICY_EXPOSURE_2018_PILOT.md)。没有从政策事件虚构收益方向或强度。要进入仿真，仍须有可靠的首次可见时间、适用地区/行业/主体映射，以及与无文本、问答单独、政策单独和合并输入相比较的预先固定消融。它解决的是外部事件信息的来源与时间表达，不代表预测有效性或市场因果效应。

数据合同位于 [`data_contracts/policy_event.schema.json`](data_contracts/policy_event.schema.json)，目录位于 [`configs/policy_event_catalog_2018_2020.json`](configs/policy_event_catalog_2018_2020.json)，校验器位于 [`data_pipeline/policy_events.py`](data_pipeline/policy_events.py)。运行：

```powershell
python -m research.data_pipeline.policy_events
python -m unittest tests.test_policy_events -v
```

来源归档在本机 Git 忽略目录 `research_outputs/observed_2018/evidence/` 和 `research_outputs/observed_2020/evidence/`。克隆仓库后运行来源哈希校验前，需先通过相应的市场数据准备流程重新归档这些证据文件。
