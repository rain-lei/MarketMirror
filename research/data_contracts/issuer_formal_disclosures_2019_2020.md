# 公司正式披露目录与财务复核合同

本合同约束[全队列披露协议](../configs/issuer_disclosures_pre_wuhan_2019_2020.json)、[三季报原文协议](../configs/issuer_q3_report_sources_2019.json)、财务页索引及[有限银行复核锚点](../configs/issuer_q3_bank_balance_review_2019.json)。来源、具体数值和限制见[报告](../ISSUER_FORMAL_DISCLOSURE_INVENTORY_2019_2020.md)。

全队列当前数值、实际列日期/范围及可比比率的后续出口另由[财务状态合同](issuer_financial_states_2019q3.md)约束。原始目录、页索引和有限锚点的范围保持不变，不与新数字层或经济模型验收混为一项。

## 公司、日期与版本

沿用行业/机制研究的冻结 123 家公司，不等同于 fresh-v3 126 家队列。公司代码与历史简称/行业来自原已冻结资料；当前巨潮组织 ID、简称及退市状态只用于获取档案，不作为历史特征。正文公司连接必须与 API 证券、组织及附件编号一致，原文 SHA-256 保留。

| 字段 | 含义及约束 |
|---|---|
| `stock_code` / `org_id` | 同证券和组织匹配；同代码基金、竞争身份或跨公司公告不得静默接受 |
| `report_period_key` / `report_end_date` | 2018 年报、2019 半年报/三季报的期间标识；不当作可用日期 |
| `provider_announcement_time_ms` / `provider_announcement_timestamp` | API 原始毫秒及中国时区解析值；不声称首次公开时刻 |
| `archive_date` | 官方附件归档路径日期，须与 API 的中国日期一致 |
| `available_at_proxy` | 归档日期次日零点；早于或等于快照才可用 |
| `publication_precision_used` | 固定为日期；不由 API 零点或其他时间虚构更强精度 |
| `report_form` | 全文、无形式后缀报告或正文，摘要/英文/附带公告不成为完整报告 |
| `revision_marked_in_title` | 标题明确的修订/更新/更正状态，保留原文，不剥去后回灌历史 |
| `attachment_url` | 限定官方归档的 PDF，附件编号与公告编号一致 |

目录快照为 2020-01-22 23:59:59 +08:00，查询公开日期范围为 2019-01-01 至 2020-01-22。每期优先全文、普通报告、正文，再选优先形式中最新可见版本；同日同形式竞争为歧义。原始返回的全部记录保留，可解释入选及排除。

`AVAILABLE_METADATA_ONLY` 只表明目录和可用代理符合要求，`MISSING_IN_CURRENT_CATALOG`、`AMBIGUOUS_REPORT_METADATA` 的 `selected` 必须为 `null`。网络或结构失败在公司层为 `FAILED`，不得将其混入成功。查询总数、各页总数、实际条数及 `hasMore` 必须完成核对，不把被截断的目录当全量。

## 原始文件和索引

三季报原文阶段只获取 123 份选定报告。API 清单保存响应原字节、请求参数、获取时间及 SHA-256；PDF 清单另存请求/最终 URL、字节数、哈希和页数，重定向不得改变附件身份。`FETCHED` 表示成功归档和容器验证，不说明财务数字、投资者行为或预测结果已验证。

财务索引保存字面标题的范围、页面及行位置、附近日期/单位和完整候选文字。合并、母公司、合并与母公司同表、标题不注明范围分开；后两者不能直接当成普通两列合并表。候选允许包含续表、摘要和年初准则调整，标题附近有日期不等于数字列所属日期。数字列未核实前，`column_order_verified=false`、`financial_values=null`、`financial_values_verified=false`。

每段单位只使用该标题开头上下文的明确证据，不借用后一张利润表或母公司表的单位。缺单位、竞争候选、缺字段保留状态；横线、空白和未出现的借款不能变成数值 0。元、千元、万元、百万元、亿元分别有不同倍数，日期、范围和数值列确认后才可归一。

## 有限复核锚点

两份银行锚点通过助手单人整页视觉复核，明确表头列序、原文单位、当前/比较日期、合并/本行范围、权益归属及续表；程序另用 pdfplumber 标签行、Decimal 和资产负债权益恒等式核对。`financial_values_verified_in_this_anchor_only=true` 只适用于明确的 18 个总额，不代表完整报告、全队列或旧财务库已验证。

平安银行标题不注明合并范围，不补造标签。郑州银行本集团包含少数股东权益，本行是另一列；不得用归属于母公司/本行的权益代替全部集团权益。银行负债包括存款，证券公司资金可能包含客户资金，不能直接当普通企业的有息借款或现金。

完整候选归档和锚点均 `agent_signal_enabled=false`，不导出股票方向、风险惩罚、金融比率或冲击系数。后续任何特征必须另有字段用途、行业适用性、单位、公开版本和历史截点校验。

## 历史可见性和增量验证

本项是截至 2020-01-22 的快照，不能把最新版本用于此前每个交易日。当前 000761 所选更新全文的保守可用时间在 2019-12-08，不能成为 11 月输入；其他更新版同样按实际公开日期处理。更早原文或合格字段缺失时，公司日继续缺失，不修改可用时间或从后发报告倒推。

年报/半年报链接尚不等于原始正文已获取；目录缺报告也不等于没有招股书等财务来源。旧 12,287 份未核实快照继续隔离。本项复核是开发资料的可追溯性工作，不是新盲留出，也不提供市场预测提升证据；后续信息增量应使用冻结同公司同日期的基线和消融。
