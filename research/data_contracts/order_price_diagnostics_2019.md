# 接受订单到成交价格：只读诊断合同

<!-- public-factor-current -->
最新[滞后沪深300暴露的公共估值通道实验](../PRE_WUHAN_PUBLIC_FACTOR_CHANNELS_2019.md)已完成80条件、3,280条完整路径、141,040个组合日及105,780条同状态提交诊断，**20/80通过原五项联合开发检查**。公共因素分别进入策略目标和所有主体报价，保持原私有消息和账户资源。全量原始来源/账本独立复核、生产五份产物及独立统计逐字节复现通过，868项测试通过；820条原样路径和35,260个完整日对象与旧归档一致。公共相加提高总估值扰动方差，结果仍来自已使用开发队列，尚未进行真实投资者校准或未使用时期验证，未采纳新默认参数；语义门槛保留。后续检验共同/行业/公司残差风险分配，继续补真实资金、库存、订单和政策预期证据；本阶段继续做研究与可复现实验。

[初始协议](../configs/pre_wuhan_order_price_diagnostics_2019.json)与[复跑环境范围协议](../configs/pre_wuhan_order_price_diagnostics_replay_v2.json)分别冻结；结果见[全量报告](../PRE_WUHAN_ORDER_PRICE_DIAGNOSTICS_2019.md)。本项读取已归档的目标/报价反馈实验，不提交订单，不产生反事实成交，不修改原价格、钱包、参数、信息时点或信号门槛。此前结果已经查看，诊断属于开发研究。

完整范围为五束、两库存锚点、四通道条件：40 条件、1,640 路、70,520 个组合日、211,560 个资产订单簿。逐个核对公司、篮子、种子、条件、连续交易序号与来源调用哈希；不能只保留一个种子或有成交记录。停牌、无成交及成交不改价分别保留。

提交、接受、前价可成交、最终价可成交及真实已成交数量必须分开。角色、风格编号、决策分支、私人消息实际送达、报价距前价位置、现金/可售库存裁剪均从真实主体规格、决策与原订单读取。参与者不得重复，背景主体只能对应本股；不能从名称推断未保存的投资者身份。实际成交买卖量必须相等并匹配双边账本。

接受买单在限价及以下有效，接受卖单在限价及以上有效。生产诊断用事件增减重建所有需求/供给不变区间；独立算法逐区间直接枚举各订单可成交量。先最大化成交量，再最小化买卖失衡，再选择距前价最近的价格；等距时沿用原取较低价规则。无成交沿用前价。最佳区间内部价位也必须覆盖，不能仅检查限价点。

互斥分类顺序固定为：停牌、没有匹配、前价本已最优、提高成交量必须移动价格、成交量相同时缩小失衡必须移动价格。最优集合位于前价之下/之上、包含前价或横跨两侧另行记录；等距取低价实际发生次数须公开。不能把分类当作真实市场原因或参与者因果贡献。

汇总保留所有 40 条件、每束与所有角色/分支/风格/送达/价格方向；初始日、1–9 日及 10–42 日分别记录。条件收益贡献按该条件全部公司日作分母；它只是可加的账本算术。五束中位数分别按字段计算，不能把不同字段的中位数当作同一条路径或相加。

独立核验必须重读全部源订单簿与诊断行，并重新核对全部真实钱包、预留资金退款、费用、股份及 T+1；每条路径第 0、10 日的三股另做完整价位扫描，共 9,840 次。每股现金预留余额不能冒充账户完整钱包；失败、未知不能填 0 或报 PASS。

原环境下三项生产产物逐字节重建，独立 v1 全量 PASS 属于历史证据。恢复复跑时旧 PDF 渲染二进制哈希不符，失败和原环境均保留。v2 仅允许一条明确路径、明确旧哈希及明确当前哈希的非执行环境差异；其余冻结文件全部严格匹配。v2 只重跑 JSON/gzip 分析，禁止新 PDF 解析、渲染及新模拟；所有独立 v1 数值字段必须完全对应，三项原产物必须逐字节一致。当前独立凭据须绑定实际二进制并声明例外，不能把旧环境符合性改报通过。

本项并未获得真实订单、投资者分类、资金流或未使用历史验证。程序和账本通过不证明市场共同结构已匹配，也不解除原 PDF 来源 QC、语义类别门槛或监管预测限制。
