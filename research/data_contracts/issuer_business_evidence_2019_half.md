# 2019 半年报业务证据合同

此合同适用于官方原始 PDF、全页证据索引、独立读取审计及有限视觉记录。它提供待核验证据，不输出已验证的业务收入比例、冲击方向或 Agent 信号。实际来源、数量、三份读取 QC 与复现步骤见[研究报告](../ISSUER_BUSINESS_EVIDENCE_2019_HALF.md)。

## 原始来源

- 同一冻结队列保留 123 个唯一证券代码，不按结果删除公司。选定元数据必须来自原披露目录的 `2019_half`，报告截止日为 `2019-06-30`，附件必须为该发行人的官方 URL。
- 122 份可选报告保持公告、归档、修订、报告期和可见性代理；688018 无选定报告时，元数据和原文为 `null`，状态为 `NO_ELIGIBLE_REPORT`。不得用后来报告或其他公司文件补齐。
- 下载成功仅核对原始字节、PDF 容器、页数及有限报告头。`FETCHED` 不代表经济字段通过；异常、大小超限、非 PDF、重试、部分字节及哈希留档，不覆盖之前失败。
- 可见性取公告日与官方归档日一致后的次日零点，保留原精度与代理依据。报告期、公开日和回取日是不同字段；修订报告不回填早期决策日。

## 证据索引

`companies` 中每家公司保留证券代码、历史简称、行业、选定元数据、原 PDF 路径/哈希、页数、逐页文本哈希及待核验状态。有源记录包含 `literal_term_pages`、`heading_candidates` 和 `region_literal_contexts`；无源时保留显式缺项，而非删除整家公司。

九个检索词和候选标题规则在读取前固定。页码为 **原 PDF 的 1-based 页码**，不是报告印刷页码，也不跨页拼接。字面匹配规范化空白和字符，不声称匹配到经济关系。候选保留原行、上下文与位置；目录、长引用和不明确标题不能被自动升级为正式表格。

- 地理信息必须区分注册/联系地址、实际经营、子公司、客户/产地、收入分区、担保对象和其他关系。当前自动索引不判定这些类别。
- 完整收入构成与仅列重大行业/产品/地区的表格分开；集团/母公司、当前/比较、收入/成本/毛利、持股比例分别核对。
- 湖北/武汉未命中、只披露境内/境外、大区无法细分、来源缺失或表格不闭合时，暴露比例均未知。不能填零、归一化部分表格或将持股比例当作收入比例。
- `NO_LITERAL_EVIDENCE_CANDIDATE` 只表示缺少本套标题或地域上下文候选，不表示整份 PDF 没有任何检索词，更不表示无暴露。

所有公司及候选的 `quantified_exposure=null`。总门槛与各公司均保持 `business_exposure_values_verified=false`、`agent_signal_enabled=false`；不得通过读到标题或通过字面审计开启它们。

## 独立审计与失败状态

独立程序不调用生产定位函数，以固定 Poppler 二进制、版本和全队列统一 `-raw` 模式读取。重新核对附件原文哈希、字节、页数、报告头、每个检索词的全部命中页以及每个原文锚点。生产、上游输入和独立执行版本均绑定 SHA-256，执行前后检查；`--audit-existing` 必须全量重建到同一字节。

| 状态 | 含义与使用约束 |
|---|---|
| `PASS_LITERAL_PAGE_MAPS` | 没有读取器诊断、字面页码和锚点一致；只认证本次定位一致性，表格数值和经济范围仍待核验 |
| `READER_DIAGNOSTIC_REVIEW_REQUIRED` | stderr 有诊断，即使文字一致也保留 QC，不标记成无问题报告 |
| `PASS_LITERAL_PAGES_CONTEXT_REVIEW_REQUIRED` | 字面页码一致但原文锚点顺序不同，候选上下文不能当作已验证 |
| `EVIDENCE_REVIEW_REQUIRED` | 某公司的读取、来源或比较失败；保存证券代码和错误，继续检查后续公司，不伪装成空白成功 |
| `SOURCE_MISSING_AS_EXPECTED` | 与冻结目录缺项一致；经济特征为空，不代表零暴露 |

任何读取诊断、锚点差异或未完成公司均使整体为 `REVIEW_REQUIRED`。已完成页数与待核验公司数属于处理计数，可以为零；它们不能作为财务或暴露零值。修订读取方案须新建配置、输出与失败历史，不对单家公司试选读取模式后静默采用最有利结果。

## 有限视觉记录与后续数值

助手单人完整原页检查仅覆盖记录中的四份报告、12 个页面，绑定原 PDF 与页图哈希。它认证所记载的有限上下文观察，不代表全部公司、表格或金额核验；原图不是独立来源，最终引用仍回到原始 PDF。

后续定量字段必须另外保存关系类型、地区定义、表格范围、单位、期间、金额列、完整覆盖/未覆盖部分、原页和公开时钟。只有来源、数字与覆盖全部核对后才能计算可比较比例；若对原数据进行更正或改变读取环境，需另建版本保留本次证据。来源门槛与市场预测门槛分别评估，未经冻结对照验证的数值不得进入 Agent 决策。

金额层另见[收入地区表合同](issuer_regional_revenue_2019_half.md)：独立核验后的有限原单位金额与表内占比有单独字段；本证据索引的未知暴露、读取 QC 和禁用经济信号规则保持有效。
