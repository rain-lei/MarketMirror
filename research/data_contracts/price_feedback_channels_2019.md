# 目标与报价中的价格反馈：完整路径合同

<!-- public-factor-current -->
最新[滞后沪深300暴露的公共估值通道实验](../PRE_WUHAN_PUBLIC_FACTOR_CHANNELS_2019.md)已完成80条件、3,280条完整路径、141,040个组合日及105,780条同状态提交诊断，**20/80通过原五项联合开发检查**。公共因素分别进入策略目标和所有主体报价，保持原私有消息和账户资源。全量原始来源/账本独立复核、生产五份产物及独立统计逐字节复现通过，868项测试通过；820条原样路径和35,260个完整日对象与旧归档一致。公共相加提高总估值扰动方差，结果仍来自已使用开发队列，尚未进行真实投资者校准或未使用时期验证，未采纳新默认参数；语义门槛保留。后续检验共同/行业/公司残差风险分配，继续补真实资金、库存、订单和政策预期证据；本阶段继续做研究与可复现实验。
<!-- /public-factor-current -->

协议见[冻结配置](../configs/pre_wuhan_price_feedback_channels_2019.json)，实际进度与结果见[实验报告](../PRE_WUHAN_PRICE_FEEDBACK_CHANNELS_2019.md)。原队列、原时期和五束随机数沿用联合反馈研究；两个库存锚点各有完整二乘二网格，不能遗漏不利条件或把内部重复当作新的历史验证。

目标通道只缩放目标分配所用风格的 `momentum_loading`；报价通道只缩放物理基础报价所用的同一原始加载。主体原参数、其他风格、共同/行业观点及私人消息均保留。目标私有观点、目标基础观点与私人贡献保留原字段，报价基础观点在非基线条件显式记为 `quote_base_beliefs`，不能把报价观点混入目标分配。

非基线主体规格须记录 `price_feedback_channels` 的 `target_scale`、`quote_scale` 和 `original_momentum_loading`；实际日记录和摘要须记录两个应用系数。原反馈不增加这些字段，并须完整匹配旧对象。

完整路径各自推进钱包、股份、可售库存、价格、确认、动量和协方差，严格沿用 `t-2` 信息、`t-1` 执行参考和 `t` 合成步骤标签。不得复用另一条件未来价格、未来账户或目标日真实收益。当前新入口只接受明确禁用文本且存在私有公司信息的实验，不改变原通用引擎。

同状态必须保持原钱包、股份、观察、协方差、消息送达和确认状态。报价变化不得改变同状态目标、请求方向或数量；目标变化不得改变基础报价观点与私人报价增量，但买卖方向变动可以改变价差和取整。假设订单不得携带虚构接受、成交或新价格，输入状态不得被修改。

声明范围为 40 个条件、1,640 条路径和 70,520 个组合日；同状态记录 52,890、四组决策审核 846,240。五束两锚点的两个对角条件须对上旧归档全部 820 条路径及 35,260 日；都关闭同状态须匹配旧 17,630 条记录。预期数从声明维度导出，各束七个非参考条件与同束参考配对的送达位置总计 4,442,760。

独立重读必须检查全量实际提交/接受/成交、撮合、费用、资源、风险历史和终值，另重建逐种子统计、中位数、配对差距与交互。所有文件在运行前后验证哈希，只写新产物；已有产物只能逐字节重建比较。任何覆盖、身份、算法、来源或结果差异须终止，不发布成功子集。

工程开发容差、机制对照、账本和测试通过均不等于真实市场匹配、现实因果、已训练交易者、盲测预测或监管放行。旧联合反馈计数失败、源 QC 和渲染器环境差异分别保留。

独立记录哈希必须遵循冻结的默认 JSON 空格合同，不能用紧凑 JSON 的哈希比对原期初状态或路径摘要。原复核器的格式失败保留；当前[v2 读取修正](../configs/pre_wuhan_price_feedback_channels_verifier_v2.json)不改变生产模型或统计门槛，只恢复哈希合同并补绑定与回归。

后续[订单到价格只读核验](order_price_diagnostics_2019.md)已完成全量撮合目标及真实钱包检查；原通道价格、结果和门槛均不改变，环境例外按新限定协议单列。

后续[现金分配合同](cash_resource_controls_2019.md)和[完整路径结果](../PRE_WUHAN_CASH_RESOURCE_CONTROLS_2019.md)已完成独立核验与逐字节复现；新实验由另行冻结的协议执行，原只读 v2 的复跑限制不变，未覆盖旧数值、环境差异或来源 QC。
