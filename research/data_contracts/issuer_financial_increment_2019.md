# 公司财务因素增量诊断合同

本合同约束[固定 2019 设计](../configs/issuer_financial_increment_2019.json)，结果与边界见[实验报告](../ISSUER_FINANCIAL_INCREMENT_2019.md)。公司金额上游仍遵守[当前财务状态合同](issuer_financial_states_2019q3.md)，不替代旧工作簿隔离规则。

## 身份、时点和配对

- 父队列为既有机制归档 123 家，财务、官方历史行业和行情发行人必须一致。四家金融机构保留排除记录，不将普通企业比率套用于银行或券商。
- 目标期 2019-11-01 至 12-31，43 个交易日。每个公司日期的 `signal_cutoff_at` 为交易所日历 `t-2` 的 15:00 中国时间；收盘是日级假设，不是实时数据零延迟送达证据。
- 财务及行业自己的 `available_at_proxy` 必须不晚于截点。报告期末、比较/重述列及后来更新版不得回灌更早时点。资料缺项、尚未公开或不适用时，`features`、`financial_decimal_inputs` 和 `target_absolute_return` 都为 null，并保留明确共同排除原因。
- 七个模型使用完全相同的合格公司日期，不按结果分别删样本。43 日共 5,289 个槽位；逐日可用公司数、全部排除和训练行数都输出，不能只报告期末 119 家而省略早期缺失。
- 名义前 30 日训练、后 13 日检查。训练目标也不得超过首个检查日的信息截点，实际 29 日训练至 2019-12-11；12-12 隔离，12-13–31 检查。所有缩放和系数仅拟合一次，检查目标不更新任何模型。

## 字段与模型

| 字段 | 固定定义 | 禁止替代 |
|---|---|---|
| `stock_volatility_20` | 截至 `t-2` 的 20 日单股简单收益样本标准差 | 当日、`t-1` 或模拟价格波动 |
| `benchmark_volatility_20` | 同窗口沪深 300 样本标准差 | 当日大盘收益或未来波动 |
| `absolute_benchmark_momentum_5` | `abs(tanh(sum(末 5 日基准收益)/(max(1e-6,20日基准波动)*sqrt(5))))` | 股票涨跌方向 |
| `log_amount_surprise_20` | `log1p(amount[t-2])` 减此前 20 日截至 `t-3` 的 `log1p(amount)` 中位数 | 盘口深度、净买卖压力或投资者类型 |
| `log_reported_assets_yuan` | 当前非母公司资产元金额的自然对数，资产须为正 | 市值、企业价值或总可交易资本 |
| `total_liabilities_to_assets` | 当前总负债/当前总资产，Decimal 50 位计算后转浮点拟合 | 有息债务率 |
| `money_funds_to_assets` | 当前货币资金/当前总资产，同上 | 自由现金或全部流动金融资源 |
| `industry_category` | 原证监会 2019Q3 门类字母，训练字母序最小门类为参考 | 今日行业替代或充分控制所有细分业务 |
| `target_absolute_return` | `abs(t 日观察股票简单收益)`，只作训练标签/检查目标 | 未来特征、当日执行输入或强制模拟价格 |

主对照为市场状态+行业 versus 同基线+三个财务字段；辅助对照为市场状态 versus 同基线+财务。两个比较全部保留，不择优报告。标准化使用合格训练行的均值和样本标准差，普通最小二乘有截距，不用 ridge 隐藏不可识别列。

总体/公司训练均值及公司固定截距+市场变量为固定参考。公司参考只使用截点前本公司训练目标，逐家公司输出计数；000761 只有一日，不能冒称稳定估计。公司固定截距使用训练期内去均值；静态财务字段会被吸收，禁止输出同时估计的伪独立财务系数。

## 指标、复核和解释

- 收益率与误差内部均为小数；展示乘 100 为收益百分点，误差相对改善率为 `1 - error_plus/error_base`，正数改善、负数变差。
- 同时输出公司日 MAE/RMSE、等交易日 MAE、当日横截面平均目标的 MAE/RMSE、逐日配对误差、负绝对收益预测数。线性负预测不裁剪；不能只挑一个汇总指标称模型已改善。
- 删一个检查日期只重算该套固定预测的误差，没有重训练。删日范围不是置信区间、独立验证或显著性证据。
- 来源和生产程序前后全量哈希检查，排他创建产物，重跑核对实际字节。另用不导入生产函数的原始 CSV/Decimal/NumPy/SVD 重建全部身份、排除、特征、预测和指标；核验通过只说明实现一致。
- 字节来源为后来回取，历史不变版本及即时行情延迟未获认证；父队列由后来的问答活跃度回溯选择，开发窗口已被查看。
- `agent_signal_enabled=false`。没有把账面规模、现金占比、负债率或线性斜率变成 Agent 股票方向、政策因果响应或已校准市场动态。
