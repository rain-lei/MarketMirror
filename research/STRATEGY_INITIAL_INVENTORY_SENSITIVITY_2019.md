# 2019 年开发期：策略初始库存与订单方向

**原策略库存本身制造了首日卖单冲击；把首日净委托调到零后，43 日累计偏卖大幅缩小，却没有解决价格与真实行情不匹配的问题。** 因此初始条件是必须披露和检验的模型假设，不能把原路径的卖压解释为三类真实投资者对风险的反应。

原无文本配置让每类 Agent 各有四个预设画像，每只股票依次持有 `[0, 300, 800, 1600]` 股。首日模拟市场历史为空、文本关闭，十二个策略账户的单股委托之和仍为 **净卖 1,700 股**：激进型净卖 600 股、保守型净卖 900 股、机构型净卖 200 股。保守型高库存画像触发风险优先减仓；其他画像也按初始持仓与目标权重之差下单。123 家公司合计净卖 209,100 股，恰好等于归档逐公司日首日总量。这是由规则和初始库存决定的首日结果，不是 2019 年或疫情信息产生的预测。

为隔离这项敏感性，事前只根据模型首日、零历史信号的委托方向选取 `[100, 400, 600, 900]` 股作为对照：三类 Agent 各自的首日单股净委托均为零。随后在相同的 2019-11-01 至 2019-12-31 开发期、123 家公司、43 日、41 个三股篮子上跑完整账户与竞价路径。三组背景订单均按固定种子以 75% 概率独立到达，买卖各半，其他策略参数和资金初值一致。前两组仅改变策略初始库存；第三组在平衡库存上换用“接受单净量”并列价规则。原库存对照的逐公司日数据与前一[订单到达实验](ORDER_ARRIVAL_SENSITIVITY_2019.md)完全相同。

另外枚举了保持四个画像总持仓仍为 2,700 股、每档为整手的全部 4,060 个初始库存向量。以当前零历史/零文本信号和相同现金配置计算首日策略委托后，没有一个向量能令总净委托为零；绝对净量的最小值为 500 股。因此 `[100,400,600,900]` 是改变总持仓后的机制对照，不能被描述为“只重排原有库存便消除首日卖压”。这一枚举由 [`simulation/audit_strategy_inventory_balance.py`](simulation/audit_strategy_inventory_balance.py) 独立重算，归档在本地 Git 忽略的 `research_outputs/strategy_inventory_balance_audit_2019_v1.json`，并绑定策略、市场和配置文件哈希。

在默认择价下，平衡初始委托使累计策略净卖请求减少约 85%，背景账户接受的净卖单也从 1,798,800 股降至 1,095,600 股；但之后 39/43 个交易日策略总体仍提交净卖单，零收益日甚至更多。单日零信号平衡不能代替多日财富、库存、风险和报价机制校准。接受单净量择价虽接近真实零收益比例，其波动仍只有真实值约九分之一，且继续把未成交意向用于选价，不宜采用为已校准规则。

按角色看，平衡库存＋默认择价的 43 日策略净请求为：激进型 -65,300 股、保守型 -282,900 股、机构型 +29,100 股；接受单净量择价则为 -117,300、-303,200、+5,000 股。平衡库存主要消除了激进型和机构型的初始卖压，却没有消除保守型的风险约束卖出。

这个对照**没有保持策略初始总持仓不变**：四画像单股合计从 2,700 股降为 2,000 股，因而也改变初始总财富、可售库存和随后资金约束。它检验的是“首日流量平衡的初始状态”整体情景，不能将多日差异全归因于画像间重新分配。样本来自后来 2020 年 1 月问答活跃池，对 2019 年是回溯选样；武汉窗口已被看过，任何后续武汉比较都不是盲验证。
