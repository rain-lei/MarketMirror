# 武汉事前回复关键词：组合关注度机制对照

更新日期：2026-09-28。

2026-09-29 当前代码复核：旧归档因仿真源码哈希变化不能直接通过严格重审；新配置[关键词组合 v2](configs/wuhan_pre_event_pit_portfolio_keyword_2020_v2.json)配对当前代码的无文本 v3 基线，已重跑 168 条路径并通过 5,880 个组合日和 17,640 次资产竞价的独立账本审计。新旧压缩账本和逐路径 JSON 哈希相同，下表经济数值仍成立。105 条公司回复到 17,640 次 Agent 资产观察的逐条来源及时点核验见[实际输入核验](WUHAN_AGENT_INPUT_ISOLATION_AUDIT_2026.md)；新产物在 Git 忽略的 `research_outputs/wuhan_pit_portfolio_keyword_attention_2020_v2/` 与对应 `_v2_audit/`。

这一组实验沿用[无文本组合基线](WUHAN_PRE_EVENT_PORTFOLIO_NO_TEXT_2020.md)的 126 家事前确定公司、42 个代码排序三股篮子、两种资金条件和 2020-02-12 至 2020-03-31 的 35 个共同交易日。每条无文本路径都在本次运行中重执行，并与其归档逐路径摘要精确比较。这里检验的是**模型机制对字面关注度假设的敏感性**，不是 DeepSeek 的语义预测或历史收益回测。

105 家公司有截点前可见的确认回复，21 家没有。冻结关键词规则在 105 条问答上产生 47 条字面候选：37 条证据来自公司回复，10 条只来自投资者提问。当前通道限定为公司回复，故排除 10 条仅提问命中；21 家无回复公司保留为空文本。命中公司只给 Agent 一个零方向信号 `text_signal=0`，并手动设置 `text_uncertainty=0.25` 或 `1.0`；未命中公司为 0。这两个数值只是风险惩罚机制参数，**不是**经标注或模型校准的事件强度、不确定度或置信度。所有可见时间经 `available_at <= t-2` 信息截止核对。

## 配对结果

每档参数各有 84 条路径、2,940 个组合日；两档合计 168 条路径、5,880 个组合日和 17,640 次资产竞价。下表每行覆盖 42 个篮子，成交股数差和平均终价差均相对同篮子、同资金条件的无文本路径；终价差以模型初价为分母。

|---:|---|---:|---:|---:|---:|
| 0.25 | 分账户 | 17.0124% | +71,300 | -0.000964 | 0 |
| 0.25 | 共享现金 | 17.0124% | +71,300 | -0.000964 | 0 |

基线每种资金条件成交 420,000 股，成交/接受为 13.1377%。惩罚增加后，策略请求和成交都改变；在有限背景订单与价格反馈下，较低目标仓位也可能伴随更多撮合成交，因此不能只凭成交股数推断行为方向。两种资金条件仍无现金裁剪，上述汇总指标相同，当前假设不识别共享现金的效果。均值没有独立市场样本意义：篮子按股票代码组成，初始资金、背景订单、Agent 风险与报价参数均未以历史盘口或持仓校准，模拟价格不拟合 2020 年实际价格。
