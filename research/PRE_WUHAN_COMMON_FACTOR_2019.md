# 2019 同日共同市场因子诊断

**价格偏差不仅来自问答信号或单股撮合；模拟股票间的共同波动明显弱于真实样本。** 本诊断在固定 123 家股票、43 个交易日的 5,289 个公司日上，比较真实收益与两种已完整回放的仿真收益：统一最近前价及沪深并列价代理。它只做同日结果的事后结构分解，不把任何真实同日指标作为 Agent 输入。

## 方法

对每个公司计算 43 日收益序列，再计算 7,503 对公司收益序列的同期 Pearson 相关。共同因子代理为同一日其他 122 家公司的等权平均收益；逐家公司用 43 日样本中该代理与本股收益的相关系数平方作为单因子描述性 `R²`。另计算 123 股的等权平均日收益在 43 日上的标准差，以及公司自身 43 日收益标准差的横截面平均。

这些是**同期描述性统计**，不是时间外预测，也没有因果解释。公司样本由 2020 年 1 月问答活跃度回溯确定，2019 年结果是机制开发期，不是独立验证。指数/市场因子用同一股票池构造，不能等同官方市场指数。

## 结果

| 指标 | 真实行情 | 仿真：统一最近前价 | 仿真：沪深并列价代理 |
|---|---:|---:|---:|
| 公司收益标准差的横截面均值 | 1.872% | 0.073% | 0.082% |
| 等权组合日收益标准差 | 0.920% | 0.019% | 0.024% |
| 平均公司对同期相关 | 0.277 | 0.058 | 0.056 |
| 公司对相关数 | 7,503 | 7,503 | 7,503 |
| 留一公司等权市场因子 `R²` 均值 | 0.307 | 0.100 | 0.127 |
| 留一公司等权市场因子 `R²` 中位数 | 0.278 | 0.069 | 0.085 |

沪深并列价代理把单股零收益比例从 60.60% 降到 46.27%，但几乎没有改善公司间相关；等权组合波动仍只有真实值的约 2.6%。这说明此前看到的主要差异不只是个股价格停滞：当前三类 Agent 分别在单股小篮子里决策，缺少可控且共同传导到多股的系统性冲击。单纯加入一个同步数字也不能自动说明政策因果、主体行为或真实市场机制已经建模。

## 对下一步的约束

应把共同冲击作为独立场景层研究，并与公司/行业暴露、政策和宏观事件分开追踪。干预实验可以使用预先写明的用户情景或只由决策时点之前资料估计的冲击分布；不能直接把同日真实等权收益或事后波动输入模型，再把相似度报作预测效果。至少要分别报告无冲击、共同冲击、公司特异冲击及组合情景，并验证冲击如何改变各类 Agent 的订单、成交、库存和价格。

另一个独立瓶颈是场所量级：既有审计发现仿真撮合只占真实同股整日成交量约 0.007%–0.011%，即使现有双边订单完全成交也只有约 0.008%。这个比例不是已识别市场份额；不能简单把所有账户扩大一万倍，也不能把整日成交量当作可执行盘口深度。共同冲击路径和订单/流动性规模必须分开校验。
