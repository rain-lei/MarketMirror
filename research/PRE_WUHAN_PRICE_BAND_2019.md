# 2019 模型价格带约束诊断

**仿真采用的固定 ±10% 价格带在四条受控路径中从未触及，因此它不是当前收益过低的直接原因。** 对比只回答模型价格带是否限制了本期模拟价格，不把历史极端收益直接标为涨跌停。

## 样本与结果

来源是已完成哈希审计的 2019 平衡共同冲击 2×2 归档。样本为 123 家公司、43 个回放步骤，共 5,289 个公司日；四组共 21,156 条公司日路径。组合场所配置中 `price_band_bps=1000`、`tick_minor=1`，所有资产使用同一固定 ±10% 模型带。

| 场景 | 模拟上/下界触及次数 | 最大模拟单步绝对改价 | 真实复权收益绝对值 ≥5% | ≥9% | ≥10% | 最大复权收益绝对值 |
|---|---:|---:|---:|---:|---:|---:|
| 无冲击 | 0 / 0 | 0.478% | 153 | 47 | 28 | 10.131% |
| 共同冲击 | 0 / 0 | 0.702% | 153 | 47 | 28 | 10.131% |
| 公司特异冲击 | 0 / 0 | 0.346% | 153 | 47 | 28 | 10.131% |
| 两者叠加 | 0 / 0 | 0.702% | 153 | 47 | 28 | 10.131% |

模型价格相对上一步合成价的最大变化不足 1%，离 ±10% 边界很远；更换冲击信念并没有使价格带开始起作用。同期真实行情出现 47 个绝对收益达到 9% 的公司日和 28 个达到 10% 的公司日，说明开发样本确有大幅收益尾部，但**这只是收益幅度计数，不是涨跌停次数**。

## 解释限制与后续数据要求

本诊断的原行情来源为 BaoStock `adjustflag=1` 的后复权 `pctChg`。该批原始响应没有未复权 OHLC、历史每日 ST 状态或逐笔排队信息，复权收益也不能可靠反推出每只股票当天适用的交易所价格限额。因此本诊断不推断具体公司是否触板、封板或排队未成交，也不把固定 10% 模型带当作交易所规则复刻。

结论是：**眼下提高价格带不太可能修复收益波动差距，因为现有模拟价格远未碰带；更大的已证实缺口仍是主体/场所成交规模和冲击传导。** 后续已单独取得未复权 OHLC、历史 ST/停牌标记和上市日期，完成[历史规则触板候选核验](PRE_WUHAN_PRICE_LIMIT_TOUCHES_2019.md)：5,289 个公司日重建出 66 个盘中触板、42 个收盘限价候选。仅按绝对收益 ≥10% 会漏判 15 个、误计 1 个。原阈值计数保留其收益幅度口径；新增候选标签只用于事后诊断，逐笔队列和特殊复牌状态仍缺证据。
