# 2019 年开发期：背景账户库存与目标再平衡审计

**持续的虚拟卖单意向主要来自背景账户吸收策略卖盘后，持仓高于其预设目标。** 这解释了为什么[并列价规则实验](PRICE_TIE_BREAK_SENSITIVITY_2019.md)里背景账户实际成交净买入，却日复一日提交净卖单；它不是对真实投资者订单流的推断。

审计读取已封存的两组 2019-11-01 至 2019-12-31 的逐资产日路径，先核对输入及程序哈希，再将每天背景账户的实际净成交加入前一天库存。另根据冻结配置的随机种子、股票代码、日序号和账户编号，独立计算每个背景账户的目标库存；此目标不读取实际行情、语义文本或当天成交。测试把独立目标公式与原背景需求函数逐项核对。两组均为 123 家公司、每股 12 个背景账户、43 个交易日；期初每个账户 500 股，共 **738,000 股**。

| 指标 | 原“靠近前价”规则 | 接受单净量择价 |
|---|---:|---:|
| 期初背景持仓 | 738,000 股 | 738,000 股 |
| 目标持仓的逐日平均 | 740,547 股 | 740,547 股 |
| 期末背景持仓 | 951,400 股 | 1,127,200 股 |
| 背景账户累计实际净买入 | 213,400 股 | 389,200 股 |
| 期初总持仓高于当日总目标且总体委托净卖出 | 43/43 日 | 43/43 日 |
| 公司日“目标－期初持仓”与背景委托净量相关 | 0.968 | 0.974 |

首日两组相同：背景持仓 738,000 股、随机目标 725,400 股，总体请求净卖 12,600 股，但实际净买入 25,300 股。此后背景账户继续吸收一部分策略卖单。到最后一个交易日，原规则路径的日初背景持仓为 952,000 股、目标 725,900 股，净卖请求 173,800 股；新规则路径相应为 1,128,000 股、725,900 股和 302,600 股。单个账户每日委托最多四手，因此委托总量不会等于“目标减持仓”的全部差额。高相关性反映的是同一套机械目标回归逻辑，**不是独立统计验证或真实市场估计**。

这说明只改变并列价无法处理订单来源：有限背景账户的固定目标与策略初始持仓共同形成持久的卖出意向，且未成交日委托到期后，下一日仍可能再次出现。下一轮模型需要先明确背景账户究竟模拟被动流动性提供者、普通投资者，还是外生订单流，再为其库存边界、订单到达和报价行为设可观察的校准目标。当前这些背景账户不能被解释为真实机构持仓。

重算入口为 [`simulation/audit_inventory_target_feedback_2019.py`](simulation/audit_inventory_target_feedback_2019.py)。本地 Git 忽略的 `research_outputs/inventory_target_feedback_2019_v1.json` 保存两组逐日库存、目标、委托和实际成交序列及来源/审计程序哈希；`--audit-existing` 会重新计算并核对该归档。所用公司池由 2020 年 1 月问答活跃度确定，对 2019 年属于回溯选样。
