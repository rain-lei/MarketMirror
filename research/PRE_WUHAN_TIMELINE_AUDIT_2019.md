# 2019 年内生市场的执行日与收益观察日

**当前归档混用了两种日期口径，不能把已有相关性称为严格的“同日市场价格复现”。** 一个回放步骤以 `t` 为真实收益观察日：Agent 信息截止 `t-2`，`execution_reference_date` 为 `t-1`。组合仿真在该步骤清算竞价，并以 `t-1` 的停牌状态决定能否成交；[成交量对照](PRE_WUHAN_MARKET_VOLUME_2019.md)也按 `t-1` 配对。但同一次竞价的合成价格变化被记录在 `trade_date=t` 的迹线下，并与真实股票在 `t` 的收盘到收盘收益配对。这个配对是**竞价反应与下一收益观察日的关联**，不是同一交易所交易日的价格和成交联合复现。

源码分别体现了这些时钟：[历史步骤构建器](simulation/historical_replay.py)给出 `t-2/t-1/t`，[组合仿真](simulation/portfolio_market.py)按执行可用性清算并把结果写入 `trade_date`，[2019 筛查入口](simulation/calibrate_pre_wuhan_market.py)用执行参考日的停牌清单，却拿 `t` 日观察收益对照竞价价格变化。现有归档、收益统计及资金/股份守恒保持原样；这项审计没有重写历史结果。

为验证这种日期差异在实际样本中能产生可见区别，[时序审计程序](simulation/audit_pre_wuhan_timeline_2019.py)从原始 BaoStock 响应重算停牌/成交状态，并复核 2019 随机到达＋靠近前价情景的 5,289 个公司日。结果如下：

| `t-1` 执行参考日 | `t` 收益观察日 | 公司日 |
|---|---|---:|
| 可交易 | 可交易 | 5,286 |
| 停牌 | 可交易 | 2 |
| 可交易 | 停牌 | 1 |

后一种情况发生在 `600489`：2019-11-27 的执行参考日可交易，模型撮合 400 股并改价约 **+0.0896%**；其后 2019-11-28 的真实收益观察日停牌、真实收益为零。这**不表示模型在停牌执行日非法撮合**；它表明把这条模型改价与 `t` 日真实收益叫作同日价格拟合会误导。反向两例中，`t-1` 停牌使仿真零成交，而 `t` 日股票已可交易并出现非零真实收益。原始响应按清单哈希及交易状态/零成交规则核对，审计归档为 Git 忽略的 `research_outputs/pre_wuhan_timeline_audit_2019_v1.json`；运行 `python -m research.simulation.audit_pre_wuhan_timeline_2019 --audit-existing` 可重算。

因此，[2019 统一筛查](PRE_WUHAN_MARKET_SCREEN_2019.md)中的历史字段 `same_day_return_correlation` 只表示**同一个回放步骤标签**下的合成竞价变化与后续 `t` 日真实收益的相关，不能独自作为“同日历史行情复现”的放行线。先前 12/12 情景未过筛的事实不变，低波动、小成交量等缺口也依然存在；但这些指标的解释必须受时钟口径约束。

下一版市场实验应先选定且冻结一个时钟合同：若目标是 `t-1` 执行后的 `t` 日结果预判，就把预测时点、目标收益和信息集显式分开，并用未参与开发的公司/时期检验；若目标是交易所 `t` 日价格与成交复现，就在 `t` 日清算并以 `t` 日的可交易状态、成交量和收益评估，同时保持下单信息严格早于清算。两种任务都不能直接复用当前“同日拟合”措辞，且不能用 `t` 日已实现收益驱动竞价。

后续已按第二种日期口径完成[2019 年 `t` 日条件实验](PRE_WUHAN_T_CLOCK_MARKET_2019.md)：它隔离了原有时钟差异，但仍只是一项已见开发样本上的未校准机制对照。
