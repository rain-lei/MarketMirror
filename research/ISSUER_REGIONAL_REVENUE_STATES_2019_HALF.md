# 半年报收入地区表：独立金额核验与有限来源状态

**问答之外的来源已从证据页码推进到可复算的收入事实：保留全部 123 家公司，55 家有通过来源读取与独立单元格核验的有限数值，共 267 个当前收入金额。** 其中 213 个有明确人民币单位，61 个占比仅以各自来源表总额为分母；16 个完整收入构成表与明示总额闭合。公司实际经营地域、客户/产地、细分武汉暴露及冲击响应系数仍未核实，不能把这些数值解释为已验证的监管预测输入。

本项承接[半年报业务证据归档](ISSUER_BUSINESS_EVIDENCE_2019_HALF.md)和[经营/资产固定增量对照](ISSUER_OPERATING_INCREMENT_2019.md)。后者没有稳定改善公司日风险误差，因此继续补充更贴近冲击传导的业务、地域和融资事实，而不是只调整问答提示。当前没有新增市场效果实验，所有经济信号门槛继续关闭。

## 固定来源与覆盖

仍使用同一 123 家开发队列、122 份原始半年报、19,586 页。来源身份、公告、归档、修订、原始字节及哈希继承上游，688018 乐鑫科技的合格半年报仍缺失。报告期为截至 2019-06-30 的半年期间，不能冒充三季度累计值。

当前金额解析限定于已冻结索引中 **69 家有地区/分部标题候选的公司**，按标题邻近页的固定范围读取有边框表格。它没有重新穷举所有页上的无边框表、图片和未知格式。69 家中 65 家产生 100 个表片段，4 家没有检测到可用表；另 53 家没有本套规则的地区标题候选，1 家缺源。以上状态全部保留，未检测到不等于没有地区收入。

| 阶段 | 本项实际数量与限制 |
|---|---|
| 当前金额候选 | 100 个表片段、269 个当前收入数值；包括部分表、公司层级行和仍有源读取 QC 的候选 |
| 独立单元格检查 | 85 个表片段通过所选单元格与计算检查；15 个无法证明当前列，明确不作为已验证数值 |
| 独立检查量 | 292 个金额单元格（269 个当前行金额及 23 个表内总额）、214 个表头单元格、61 个表内占比 |
| 有限来源状态 | 55 家公司、267 个当前数值；其中 213 个可按明示人民币单位换算，54 个不自动赋予人民币币种 |
| 完整收入构成闭合 | 16 个 `FULL_REVENUE_COMPOSITION` 表；闭合只认证收入构成与该表总额，地域分配含义仍未知 |

独立检查没有发现实际单元格数值差异或执行错误；15 个当前列不明状态按预期保留。85 个表片段通过检查不代表 85 家公司通过，也不代表整份报告的所有金额、经济关系或地域定义通过。

## 解析、跨页与独立复核

[v2 候选读取](data_pipeline/extract_issuer_regional_revenue_v2.py)使用原 PDF 的物理边框、表头、行标签和单元格坐标。当前金额列须由报告本期及收入表头证明；金额通过 Decimal 保存，跨行数字仅在同一物理单元格内拼接。缺值、横杠和不明列保持空值，原文实际零值与负抵销保留。

跨页延续同时要求物理相邻页、相容列边界、同一业务范围和单位；新章节、其他正文、单位变化及前段未解决问题阻止静默续接或比例计算。只允许报告页眉/页码和单位等有限间隔。v1 99 个表片段及其冻结配置保留为初始候选；新增回归检查发现续表可能丢失前段缺值问题，v2 修复后固定配置再运行，得到 100 个表片段。当前推荐 v2，不把 v1 当作已通过独立数值门槛的出口。

[独立审计](data_pipeline/audit_issuer_regional_revenue.py)使用 pdfplumber 0.11.10，不导入生产的表头分类、数字解析和比例函数。它要求候选坐标附近 3 点范围内唯一物理边框单元格，重新核对表头、范围、单位、行标签、符号、换算、缺失与总额。缺失或歧义直接进入 QC；不能从同页其他位置挑选相同数字冒充对应单元格。只有原文明确总额、全部相关行可用、范围一致、精确求和闭合且印刷百分比在其舍入精度内一致时，才核验表内占比。

[状态构建器](data_pipeline/build_issuer_regional_revenue_states.py)按公司及唯一表索引连接候选和独立结果，同时检查上游读取状态。通过数值检查后，仍必须另外有明确 CNY 单位证据才生成 `verified_current_revenue_yuan`；单独“元”不自动解释为人民币。主营业务及重大分部占比保留本表分母，不能当作发行人全部收入比例。全部 `complete_geographic_allocation_verified` 保持 false，`finer_geography_exposure` 保持 null，股票方向 unknown。

## 可见时间与研究边界

报告可见性仍为公告日与归档日一致后的次日零点代理；不是精确首次公开时间。修订版本 600448、603156、603789、603959 分别从 2019-09-14、09-19、09-22、10-13 的代理时钟可见，不能回填此前日期。2026 年回取的字节尚未认证为当年未变版本。

123 家开发队列与已查看日期继续作为开发材料，不与第五批 126 家、其他留出样本混合，也不重新称为盲验证。本项只补来源数值，不读取目标收益寻找有利的地域分组，不新增市场系数或开启语义/经济信号。闭合、测试通过和重复读取一致均不是风险预测改善的证据。

1. 扩展缺候选、无边框和银行/券商矩阵的来源核验；补充表格自己的地域定义、集团/母公司及非地域其他收入。沿用统一规则和独立读取，缺源与未知不得转为零。

4. 单独推进订单规模、资金/库存和共同市场结构的校准。来源核验、预测增量和 Agent 机制分别验收，通过新的固定对照后才考虑接入决策。
