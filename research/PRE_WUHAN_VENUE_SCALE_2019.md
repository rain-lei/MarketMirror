# 2019 开发期场所订单规模审计

2019 年 `t` 日同一竞价日口径的仿真成交量仅为真实整日成交量的 0.00724%。本审计进一步拆分了这项差距：**即使当前每个公司日的双边已接受订单都能完全互相成交，仿真量至多也只有真实整日成交量的 0.00795%。** 因而当前参数下的主要限制是进入小型仿真场所的双边订单规模，而不是既有订单之间未能撮合的余量。

固定样本是 123 家公司、2019 年 43 个交易日，共 5,289 个公司日。`research.simulation.audit_pre_wuhan_venue_scale_2019` 从已归档的逐日请求、接受与成交股数重新求和，再从 BaoStock 原始文件重建同一 `t` 日的真实成交股数。它逐行检查请求量不小于接受量、双边成交股数相等、成交不超过两边已接受量，以及停牌状态；同时要求独立重算的真实与仿真成交量汇总等于原 `t` 日归档。来源和代码哈希保存在 Git 忽略的 `research_outputs/pre_wuhan_venue_scale_audit_2019_v1.json`。

| 股数或比例 | 结果 |
|---|---:|
| 仿真请求买入 / 卖出 | 6,313,000 / 8,436,100 股 |
| 仿真接受买入 / 卖出 | 3,857,400 / 7,833,300 股 |
| 各公司日 `min(接受买入, 接受卖出)` 之和 | 3,570,800 股 |
| 实际仿真撮合 | 3,253,300 股 |
| 同公司同日真实整日成交 | 44,940,700,279 股 |
| 仿真撮合 / 逐日双边上限 | 91.11% |
| 逐日双边上限 / 真实成交 | 0.00795% |
| 仿真撮合 / 真实成交 | 0.00724% |

这里的“双边上限”只是在**保持每个公司日现有已接受买卖股数**时，忽略限价差异所能形成的机械上界，不是可执行流动性，也不是外部市场订单簿。请求量和接受量来自模拟主体，不是投资者真实订单流。真实成交量覆盖整个交易所的整日交易，仿真是一个小型场所；两者的比值不能直接解释为已识别的市场份额。股票池根据后来 2020 年问答活跃度回溯选择，2019 年数据已用于开发，因此这些数字也不是独立校准检验。

下一步若要检验历史市场复现，必须先确定仿真场所要代表的市场范围和可观察的订单/流动性目标，再设计新的参数与独立公司或时期验证。单独改变并列价格规则或提高当前订单的撮合率，最多只能填补双边上限与实际撮合间的 317,500 股，不足以弥合与整日真实成交量的数量级差距。

重算命令：`python -m research.simulation.audit_pre_wuhan_venue_scale_2019 --audit-existing`。
