# 2018/2020 三类 Agent 行动区分度审计

**结论：现有三类预设 Agent 在模型内经常作出不同买卖/持有决定，但没有证据证明这些决定贴合真实投资者类别或复现政策、疫情冲击。** 本审计读取三段已归档历史收益回放，先核对来源清单和文件哈希，再逐股票、逐交易日比较激进、保守、机构角色的行动，并比较每个角色的市场动量与零信号路径。计算结果重新从来源生成且逐字匹配归档 JSON/报告；另一段独立计数也复核了总日数、角色异同行动日和激进角色的信号影响日。

| 时段 | 股票×交易日 | 三类至少两种不同行动 | 全部行动相同 | 市场信号改变行动：激进/保守/机构 |
|---|---:|---:|---:|---:|
| 2018 上半年 | 357 | 282（79.0%） | 75 | 273 / 160 / 98 |
| 2020 一季度 | 174 | 138（79.3%） | 36 | 142 / 93 / 43 |
| 2020 后续时期 | 555 | 466（84.0%） | 89 | 472 / 263 / 165 |

每个时段均为平安银行、万科 A、贵州茅台三只预选股票。市场信号是决策前可用的**宽基历史收益动量**，三段每个股票交易日均非零；零信号路径使用相同观察收益、参数与成本。激进角色通常更频繁买卖，机构角色的重平衡等待更频繁。这些差异是固定角色参数、账户状态和历史价格输入的机械结果。它们不是由 2018 资管新规或 2020 武汉通告的文本驱动，也没有与真实投资者类型、持仓、委托、净订单流或盘口逐项匹配。

回放价格按已经发生的股票收益外生推进，Agent 不影响价格；满额参考价成交、固定成本和初始资金仍是假设。因此可确认的是**代码内角色行为可区分**，不能称为“成功复现三类真实交易主体的决策路径”或“预测监管冲击”。下一步若要检验原设计的实证主张，应先明确可观察的角色代理和校准目标，取得对应交易/持仓或订单流证据，并用独立时期验证；在此之前保留这些角色作为机制情景。

可重算程序为 [`simulation/audit_agent_role_separation.py`](simulation/audit_agent_role_separation.py)。本地归档位于 Git 忽略的 `research_outputs/agent_role_separation_2018_2020_v1/`，含 JSON、报告和输入/代码/产物哈希清单。`--audit-existing` 从三段原回放重算并核对归档内容；单元测试覆盖角色异同行动和市场/零信号差异计数。
