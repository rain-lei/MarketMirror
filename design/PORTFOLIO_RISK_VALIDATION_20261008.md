# 收益、风险与执行指标核验

2026-10-08。结果分析与真实原文案例共用组合指标模块，读取已保存的收盘账户、撮合订单、协方差和角色参数。新增指标不改变市场引擎、冻结研究归档、策略规则或模型事实。

## 计算及展示

- 按每类账户的现金与三资产收盘市值合计计算组合净值，初始值包含初始库存。收益使用期末合计 / 初始合计；最大回撤从初始值和逐步收盘值的历史峰值计算，不平均各账户回撤。
- 费用仅合计该角色的订单费用，不包含背景账户。成交比例以全程请求股数为分母，包括未被接受的请求；没有请求时显示“未下单”，比例在 JSON 中为 `null`。
- 风险/总仓位超限按当步协方差、实际收盘仓位、风险预算及最高总仓位重算，集中度超限按实际收盘单资产权重与当步存档上限重算。判定容差与现有引擎一致，均为 `1e-9`。
- 超限同时报告账户 × 步和至少一个账户超限的步骤数。首个超限按钮选择对应路径和步骤，保留资产选择；可以继续查看已有的决策与订单依据。
- 净值、账户角色、步骤数量、协方差、费用和订单字段缺失或不一致时，相应指标保留未知并列出原因，不补零。期末净值与汇总不一致时拒绝生成收益与回撤。
- 指标 JSON 使用 `portfolio-risk-overview-v1`，包含单位、原始结果来源标识、路径哈希、逐步净值和超限账户。导出当前读取版本，不重跑实验或调用模型。
