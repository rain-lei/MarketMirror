复现命令（输出目录必须不存在，避免覆盖旧证据）：

```powershell
python -B -X utf8 -m design.scenario_batch --output research_outputs/my_scenario_batch
```

`batch.json` 保存逐项状态、路径哈希、收益差和成交统计。`workspace/` 保留完整实验与账本，可单独启动查看：

```powershell
python -B -X utf8 -m design.server --port 8772 --data-dir research_outputs/my_scenario_batch/workspace
```

此次完整产物位于本机 `research_outputs/platform_batch_20261006_a` 与 `_b`，不随 Git 分发。
