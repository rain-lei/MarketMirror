# 三类策略参数编辑核验

2026-10-06。改进策略配置页与新实验参数区的编辑控件，解决范围不明显、只能拖动以及显示会取整的问题。三类 Agent 的研究规则、冻结配置、原有实验和实际模型事实没有修改。

## 行为

每个参数提供角色颜色的范围条、圆形滑块、上下界、精确数值输入及当前数值。使用后端提供的真实角色范围；连续滑块可以表达不落在原刻度上的值，方向键按原参数步长移动，Shift 加方向键移动十个步长，边界截断。保留原生键盘 Home／End 行为。

文本敏感度使用系数；基础权重和风险预算按百分比显示与输入。例如风险预算输入 `0.83` 表示 `0.83%`，内部保存为 `0.0083`；基础权重输入 `33.3333` 保存为 `0.333333`。显示不再把基础权重强制取整。微小非零系数使用科学计数法，缺失字段显示“未存档”。

数字框清空、非有限值或超出范围时显示字段错误，保留最后有效草稿，不把空值转换为零。策略页阻止保存；新建流程阻止进入确认，并在主表单提示修正参数。修正数值或拖动滑块恢复有效值后重新启用操作。保存操作自身也检查无效输入，不只依赖按钮的 disabled 属性。

编辑实验参数只保存当前实验草稿；编辑工作区参数要显式保存才影响之后的新建实验。已有实验独立保留快照，未被 UI 编辑或默认值修改覆盖。保存期间输入禁用，状态层仍拒绝迟到编辑。
