# MarketMirror 本机仿真实验平台

当前可用流程：输入消息 → 可选 DeepSeek 事实提取 → 手动设置情景 → 运行有消息 / 无消息对照 → 查看三类策略与逐步撮合 → 导出实验。平台数据存于 `research_outputs/platform_workspace/`，研究协议与冻结结果独立保留。

## 启动

在项目根目录执行：

```powershell
.\scripts\start-platform.ps1
```

浏览器打开 `http://127.0.0.1:8770`。脚本会检查端口并在当前终端前台运行服务，按 `Ctrl+C` 停止；也可直接执行 `python -B -X utf8 -m design.server --port 8770`。服务默认只监听本机；不指定端口时使用 8770。

当前交付状态（2026-10-06）：本机撮合记录、批量情景、6 个真实原文案例和 1 个真实历史收益实验已接通。三类策略支持彩色范围滑块及精确数值输入；页面说明共享的规则引擎与 DeepSeek 事实提取之间的关系。逐步账本、共用消息时间轴、同一步对照和草稿刷新恢复可用。最新平台回归为 Python 82 项、Node 104 项通过。干净 Git 副本已验证无需研究归档也能完成合成实验和导出；缺少历史归档时相应页面明确提示。最终浏览器视觉检查的剩余范围见[历史行情接入核验](OBSERVED_PLATFORM_VALIDATION_20261006.md)与[参数编辑核验](PARAMETER_EDITOR_VALIDATION_20261006.md)。

本机已完成一条当前平台的真实原文端到端运行：武汉交通通告经 DeepSeek 提取 4 条事实，创建带分析快照的实验并完成 36 个市场日审计。详细编号和边界见[真实原文端到端实验核验](REAL_SOURCE_EXPERIMENT_VALIDATION_20261006.md)。

## 策略与精确参数

三类 Agent 共用参数化决策引擎，以敏感度、风险预算、确认和再平衡约束表达不同偏好，目前没有分别训练三个投资者模型。策略配置页和新实验的策略参数区均支持范围标注、彩色滑块、原生键盘控制和精确数值输入。直接输入不会量化到原有拖动刻度；百分比按字段单位换算，空值和越界值不会覆盖有效参数，也不能直接保存或进入确认。

新建实验采用当时参数的独立快照；调整工作区默认不会改写已创建实验。校验范围从后端配置读取，不另行改动冻结的角色规则或研究结果。

## 文本分析与依据

- 新建实验中使用 `DeepSeek-V4-Flash-0731-W8A8` 提取事实，后端复用已保存的本地凭据，调用既定网关。浏览器不接收密钥。
- 原文、事实、逐字引文及位置、模型名称、提示词哈希、原始模型输出与分析时间一起存档。引文匹配只验证引用来自原文，不保证模型语义判断正确。
- 创建实验时，后端核对分析 ID、完整原文与哈希、事实结构和引文位置，并将分析完整快照写入实验。之后修改独立分析文件不会改变已创建实验的依据。
- 编辑原文立即取消旧关联；即使改回原文，编辑前发出的迟到响应也不会重新绑定。新建或切换草稿同样会丢弃过期响应。取消等待只停止采用返回结果，不中止已发出的模型请求。
- 运行时再检查快照一致性。导出同时保留实验、分析依据、版本标识、撮合账本与关联哈希。
- 全新实验默认信号为 0，避免未经判断便带入正向情景；复制实验保留原信号。中性信号不等于无消息，不确定性仍可影响策略。
- 模型提取仅作情景设定参考。信号、强度、不确定性和持续步数由用户手动设置，不自动解释成真实价格冲击。也可以跳过模型分析直接运行。

## 合成市场与结果

新实验调用 `design.engine.run_market`，模式为 `synthetic_market`，复用已有三资产组合撮合引擎与三类策略参数。两组共享初始条件和随机种子，每个市场日都执行账本审计。结果页可切换资产、回放决策步、查看目标仓位和订单请求 / 接受 / 成交，以及三类策略期末收益对照。逐步决策卡可在有消息组与无消息组之间切换并读取对应真实账本；两组价格图使用相同的坐标刻度。实验空间显示运行中、失败、已中断和完成状态，已保存实验可重试。

当前实验假设：

- 消息从第 5 个决策步作用于资产 A，持续 3、6 或 9 步。作用期结束后新的文本输入清零，但此前的成交、持仓和价格变化可能继续影响后续决策。界面和 API 均支持 1–60 步，默认 18 步；少于 5 步时消息尚未生效。
- 激进型、保守型、机构型各有 4 个账户。每类初始现金按 12 个资产钱包分配并向下取整到分，实际每类合计显示在结果页；每账户每资产另有 500 股初始库存。背景账户有独立资金与库存。
- 发布时间随消息保存；引擎内部日期只用于顺序控制，不是对该日期真实交易日的回放。
- 输入为合成情景，价格与收益不能作为历史预测准确率或投资建议。

三条虚构消息保留为示例模板，点击复用进入新建流程，实际保存并运行后才产生自己的撮合结果。旧的手写示例收益、仓位和成交图已移除。早期 `platform_preview` 记录仍可读取，标注为历史预览，其中成交量是旧版演示值。三类策略配置已接入实际撮合：文本敏感度、基础股票权重与风险预算均可编辑。工作区默认配置保存于 `settings/strategies.json`；每次新建实验复制一份独立参数，可在向导中单独覆盖。保存工作区配置不会修改已创建的实验。结果页和导出文件均保留实际使用的参数与哈希。复制实验时优先恢复原实验参数；旧版撮合实验从历史参与者账本恢复参数。

## 策略参数约束

文本敏感度范围为 0–2，风险预算为 0.001–0.08；基础股票权重不能超过各角色固定持仓上限（激进 100%、保守 55%、机构 80%）。拒绝缺失角色、未知字段、非有限数、布尔值或字符串数值。连续确认步数、再平衡间隔和其余策略规则保留基础配置。每次运行校验策略快照哈希和基础配置哈希，发现变化则拒绝执行，避免结果与存档参数不一致。研究配置文件只读。

## 界面与存储

深色导航、浅色工作区与青绿主操作色；三类策略分别使用赭橙、蓝和紫，并附文字标签。支持实验搜索、新建向导、事实证据卡、逐步决策查看、消息资料复用、深浅主题和窄屏布局。已保存实验从本机服务读取，同一浏览器标签页刷新后恢复最近打开的实验；记录或结果加载异常会明确提示，不会伪装成已完成。单条记录读取失败不影响其他正常记录加载，提示中列出失败编号；重新加载成功后自动清除提示。

默认首页为实验空间。“本机实验”与“示例模板”分别筛选，导航计数仅含本机记录。首次加载分析页优先选择撮合实验，不使用模板填充图表；未选中可读实验时显示新建与选择入口。详情读取复用 JSON 导出接口的配置 / 结果快照，避免分次读取时混合运行版本；每批最多四个请求，迟到刷新不能覆盖当前数据，新建实验会取消旧列表的采纳。旧版缺少来源标识的结果继续兼容；已有标识发生矛盾时拒绝加载。详见[记录读取核验](EXPERIMENT_LOADING_VALIDATION_20261006.md)。

主要接口：

- `GET /api/platform/strategies`：工作区默认参数、编辑范围与固定规则。
- `POST /api/platform/strategies`：保存完整工作区参数。
- `POST /api/platform/analyze`：提取、验证并保存文本分析。
- `GET /api/platform/analyses/{id}`：重新核验并读取已保存分析；不调用模型。
- `GET /api/platform/model`：读取后端模型、本机凭据状态和最近连接检测，不调用模型。
- `POST /api/platform/model/check`：仅接受空对象，使用固定合成文字检测生产事实提取接口。
- `GET /api/platform/experiments`：实验列表。
- `POST /api/platform/experiments`：创建实验；可通过 `analysis_id` 关联依据。
- `GET /api/platform/experiments/{id}`：配置与分析快照。
- `POST /api/platform/experiments/{id}/run`：运行并审计撮合。
- `GET /api/platform/experiments/{id}/result`：读取结果与依据关联。
- `GET /api/platform/experiments/{id}/export`：下载归档配置、文本依据和完整结果。
- `GET /api/platform/health`：本机服务状态。
- `GET /api/platform/observed-experiments`：登记的历史收益实验目录，读取不调用模型。
- `GET /api/platform/observed-experiments/{id}`：核验原始归档并返回三条件路径与来源解释。
- `GET /api/platform/observed-experiments/{id}/export`：导出原始模型、复核、路径及展示层补充解释。

## 批量情景对照

左侧“批量对照”页面支持创建和查看持久化批次：1–10 个不重复种子、每项 1–60 步、消息持续 3/6/9 步和每类初始资金。每个种子运行中性（0/0）、正向（0.6/0.2）、负向（−0.6/0.2）及高不确定性（0/0.8）四种情景，数字分别为信号与不确定性。创建时复制工作区已保存的策略配置并冻结哈希，不使用未保存的草稿，也不调用 LLM。

后台按项运行；关闭页面不停止计算，停止本机服务后未完成批次标记为中断。单项失败继续后续项，重试跳过已完成项。页面显示完成数、失败原因、逐项订单量，以及三类策略的跨种子均值与最小最大范围。缺失项不补零、不进入汇总。范围仅作描述性比较，不表示置信区间。

“查看决策”读取批次冻结的 `result_id` 及路径哈希，即使该实验之后单独重跑，原批次及其归档视图也保持不变；在归档视图导出同一份已保存结果。批次记录存于 `research_outputs/platform_workspace/batches/<id>/batch.json`，实验账本仍在各实验目录，可下载中文 Markdown 报告。

接口：`POST /api/platform/batches` 创建，`POST /api/platform/batches/{id}/run` 异步启动或重试（202），`GET /api/platform/batches` 列表，`GET /api/platform/batches/{id}` 进度和统计，`GET /api/platform/batches/{id}/results/{experiment_id}` 固定归档，`GET /api/platform/batches/{id}/report` 报告。重复启动正在运行或已完成批次返回 409。

本轮自动化核验及实际 12 项批次见 [页面批次核验](BATCH_PLATFORM_VALIDATION_20261006.md)。

运行 `python -B -X utf8 -m design.scenario_batch --output research_outputs/my_scenario_batch`，创建四情景、三种子的独立实验目录。每项完成后更新 `batch.json` 和中文 `report.md`，失败项保留状态且收益留空。支持 `--seeds` 与 `--sessions`；输出目录必须不存在。实际运行结果与限制见 [批次报告](SCENARIO_BATCH_20261006.md)。

## 真实原文案例

左侧“真实原文案例”读取六个已实施的开发案例：2018 资管政策答记者问、2020 武汉交通通告、上交所春节休市公告，以及特殊审批、已有间接持股和仅提示关注公告的三条公司回复。四个条件为无文本、简单关键词、复核后 LLM、LLM 资产暴露置换；种子固定为 7、11、23、47、89，共 120 条原始路径。每次查看以同一种子的无文本路径作为对照。

页面展示完整来源和可用时间、原始模型事实、助手修订与理由、预先声明的数值映射，支持按引文定位原文。三类卡片与价格曲线读取所选归档，按资产、步骤与条件切换；信息截点和执行参考日均来自归档。武汉案例首个可见步骤为第 4 步，不套用普通实验的第 5 步。收益表是完整路径差异，包含既有持仓与价格反馈，不作为纯文本因果效应。

无文本条件使用同一路径自对照，预期差异为零，只计 18 个不同市场日；其他条件读取两条路径，计 36 个市场日。这些数值是归档核验范围，不是市场预测评分。

`design/source-case-registry.json` 固定研究协议和归档总清单哈希。读取时核对来源绑定、复核身份、摘要范围；所选两条路径再核对原始文件哈希、事实、信息时钟、决策解释、每日结算和期末账户。损坏归档返回 503，缺失归档不会生成替代结果。同一选择刷新失败时保留上次读取的归档并提示；切换案例、种子或条件后迟到响应不能覆盖新选择。归档缓存每次仍先核对原文件哈希。

导出包含所选条件和无文本路径、原文、原始与修订事实、映射、配对统计和版本标识。“以此原文新建实验”复制来源与时间，使用当前策略配置并重新设置情景；不关联旧模型分析、不复制旧市场结果，也不改变登记实验。

接口均为只读：

- `GET /api/platform/source-cases`：本机归档是否可用及六案例目录。
- `GET /api/platform/source-cases/{id}?seed=7&mode=reviewed_llm`：核验并读取所选条件。
- `GET /api/platform/source-cases/{id}/export?seed=7&mode=reviewed_llm`：下载同一数据包。

原文、原始模型响应及压缩路径保存在 Git 忽略的研究目录，不随新克隆仓库分发。需要已有归档及其绑定来源；缺少时合成实验仍正常使用。查看不发送新模型请求、不重新执行市场。源文和日历来自真实资料，价格、投资者规则、暴露与数值强度为假设；六例已用于开发，不能视为独立语义准确率或市场预测验证。

全范围只读核验：`python -B -X utf8 -m design.source_cases --verify-all`。本轮实际 HTTP 与视图检查、平台回归和浏览器验收边界见[案例核验记录](SOURCE_CASE_PLATFORM_VALIDATION_20261006.md)。

## 新建实验的后台提交与恢复

运行时可切换页面或新建另一份草稿。每次提交固定消息、分析关联和参数；完成后保存在实验空间。离开原确认页、改动配置或建立新草稿后，旧结果不会强制切换当前页面。同一份等待中的草稿禁止重复提交，已保存的失败记录从原实验恢复运行。

保存响应丢失后重试沿用原提交编号，服务端返回原配置及当前运行状态。接口 `POST /api/platform/experiments` 可携带 `Idempotency-Key`，值为 32 位小写十六进制编号；重复编号必须对应同一份规范化配置，冲突返回 400，未携带该头的原客户端保持兼容。提交编号由页面自动生成并随当前标签页的草稿保存，刷新后继续使用。其他浏览器通过实验空间读取已保存记录，不同步未提交草稿。

提交与恢复的早期阶段回归为 Python 58 项、Node 57 项；最新完整回归为 Python 75 项、Node 84 项。独立服务的丢失响应检查、实际浏览器流程和限制见[草稿与浏览器核验](DRAFT_RECOVERY_VALIDATION_20261006.md)。

## 同一步决策对照

普通撮合结果及真实原文案例在时间轴下方同时显示三类策略的两组对照。资产与步骤切换后，目标资产权重、决策前权重、判断分值、请求／接受／成交股数及差值来自所选账本；权重条共用 0–100% 范围。权重与分值分别按各路径的决策前净资产加权，股数为当前资产的买卖合计，方向和账户明细仍在决策卡中。

普通结果页上方提供“查看同一步决策对照”按钮，滚动到时间轴并转移键盘焦点，不改变所选实验、资产、步骤或路由。

收益差等数值显示六位小数，极小非零值使用科学计数法；缺失角色或预期账户决策不冒充零合计。两条完整路径可能已有不同持仓和价格，显示差异不表示固定状态下的纯文本效应。

## 模型设置与连接检测

侧栏底部的“模型设置”读取后端实际模型和接口地址，显示凭据已保存、缺失或无法读取；密钥不返回浏览器，不要求每次输入。模型及网关沿用当前指定配置，界面只读。

打开或刷新只读取本机配置，点击“检测连接”才调用模型。检测使用固定的虚构公司审批文字，复用生产事实提取提示词和引文验证；不发送草稿、不创建分析或实验。重复检测被阻止；关闭窗口不取消已发出的请求，迟到结果也不会覆盖其他弹窗。检测响应丢失时可以刷新读取服务端状态，不据此宣称成功。

最近检测保存在服务内存，重启后需重新检测；本机凭据改变时旧检测失效。通过表示请求完成且事实与引文结构合格，零事实也可为有效结果，不代表事实判断或市场预测准确。调用失败区分凭据、限流、超时、网络、网关和返回内容问题；不保存失败的分析，也不回显网关错误正文。

模型连接阶段回归为 Python 70 项、Node 72 项；最新完整平台回归为 Python 75 项、Node 84 项。实际连接检测、生产入口和界面验收边界见[模型连接核验](MODEL_CONNECTION_VALIDATION_20261006.md)。

## 草稿自动保存与刷新恢复

每个标签页保存一份草稿，内容包含原文、发布时间、情景变量、独立策略参数、创建步骤、分析编号和固定提交配置。编辑字段和策略后立即写入 `sessionStorage`；数值下拉框保持数值类型，零值不作为缺失。新建实验主动清除上一份草稿，实验空间的“继续草稿”返回当前草稿。缓存或存储不可用时明确提示，不宣称保存成功；其他会话设置不受清除草稿影响。

浏览器缓存不保存模型事实、原始模型响应或密钥。恢复时只按编号 GET 本机分析，服务端重新校验原文哈希、引文位置、结构和身份。缺失或损坏的分析需要重新读取，或明确取消关联后手动运行；不会自动外发原文。恢复途中改动来源或建立新草稿后，迟到结果不能绑定到新内容。

刷新后先从本机列表与完整快照核对原提交。已完成实验打开原结果，运行中的实验只查看进度，失败实验从原记录恢复；保存状态未确认时保留同一提交编号。缓存中的旧运行状态不作为成功凭证，配置不匹配的服务端记录不认作本次提交。

2026-10-06 最新回归为 Python 75 项、Node 84 项通过。实际 HTTP 丢失响应检查、真实浏览器刷新流程、一次虚构文字模型提取与三种窗口宽度验收见[草稿与浏览器核验](DRAFT_RECOVERY_VALIDATION_20261006.md)。
