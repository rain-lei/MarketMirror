# 平台使用与接口

平台操作链路：原文 → 可选事实提取 → 情景与策略配置 → 两组市场仿真 → 逐步解释 → 报告导出。安装及启动见[项目首页](../README.md#快速启动)。

## 实验与草稿

首页“实验空间”显示本机记录，示例模板只提供可复用的虚构消息。新建向导依次填写来源、设置情景、编辑策略和确认运行。默认信号为 0，跳过模型提取也可运行。

草稿在当前标签页的 `sessionStorage` 保存原文、参数、步骤、分析编号和提交编号。刷新时按编号从服务端重新读取分析，核验原文与引文；缓存不保存模型响应或凭据。编辑原文会解除分析关联，迟到响应不会重新绑定。存储不可用、记录损坏或关联缺失时会提示。

提交配置固定后可以切换页面或编辑另一份草稿，结果保存在原实验中。保存响应丢失时沿用同一提交编号重试，避免重复创建。失败和中断记录可重新运行；运行中的记录不重复提交。

## 三类策略与决策预览

| 策略 | 规则侧重 |
| --- | --- |
| 激进型 | 对信息更敏感，较快调整目标，允许较高风险暴露 |
| 保守型 | 降低风险预算，等待确认，抑制不确定消息下的交易 |
| 机构型 | 结合组合风险、集中度和定期再平衡分配资金 |

三类共用本地决策引擎。DeepSeek 提取文本事实，不直接生成交易指令；角色参数为预设行为假设。

策略配置页和向导支持滑块、键盘及精确数值输入。文本敏感度为 0–2，风险预算内部值为 0.001–0.08；界面百分比按单位换算，输入 `0.83%` 保存为 `0.0083`。基础权重不得超过固定上限：激进型 100%、保守型 55%、机构型 80%。空值、越界和非有限数阻止保存或确认，不覆盖最后有效值。

工作区默认参数保存在 `settings/strategies.json`。每份实验复制独立快照及哈希，修改默认值不改变已创建实验。确认步数、再平衡间隔等固定规则由后端配置提供。

“同状态决策预览”给各角色相同的现金、持仓、价格、协方差和观察记忆，分别计算有消息与无文本目标。预览调用实际规则，不下单、不撮合，也不调用模型。它显示分值贡献、目标、拟调仓及约束原因。输入无效时结果失效，过期响应不覆盖新条件。

点击“用此情景新建实验”带入信号、范围、市场偏移、波动率和策略，并保存预览参考。完整实验重新从初始账户积累记忆，预览的人工观察状态只作为参考。

## 情景与撮合

新实验模式为 `synthetic_market`，两组共享初始条件与种子。每组包含 A/B/C 三资产、每类四个策略账户及独立背景账户；逐日审计现金、股份与费用。

| 设置 | 范围与含义 |
| --- | --- |
| 信号 / 不确定性 | −1 至 1 / 0 至 1；手动情景变量 |
| 消息范围 | 资产 A 或全部三资产 |
| 消息时长 | 第 5 步进入，作用 3、6 或 9 步 |
| 总步数 | 1–60，默认 18；少于 5 步时未收到消息 |
| 市场偏移 | −1 至 1；从第 1 步进入两组，与内生价格反馈叠加 |
| 波动率下限 | 0.001–0.5；用于逐日协方差计算，默认 1% |
| 种子 / 初始现金 | 0–999999 / 1 万至 1 亿元 |

每类策略初始现金分给 12 个资产钱包并按分取整，每账户每资产另有 500 股初始库存。收益计算包含初始库存。消息到期后新增文本输入清零，先前成交、持仓、记忆和价格反馈仍可能影响后续路径。发布时间保存为来源元数据，不将合成日期解释成真实交易日。

## 结果与比较

结果页按资产、信息条件和步骤读取归档账本。时间轴支持滑块、步骤格、前后按钮和直接输入，标出日期、消息进入及作用区间。普通情景使用假设步数，归档案例读取各自的来源时钟。

“同一步决策对照”同时展示三类策略的两组目标、分值、请求、接受和成交。微小非零差异不会显示成零，缺失字段保持未知。目标计算触及 0% 下限或风险/仓位上限时，在可从归档输入核对的情况下显示限幅前后值；确认等待和风险减仓不误报为普通限幅。

两条完整路径可能已形成不同账户与价格，对照包含先前交易和反馈。研究因果通道时使用同状态预览或登记的固定状态实验。

“收益、风险与执行”按整类账户净值计算收益与最大回撤，统计该角色费用及成交占请求比例；没有请求时显示“未下单”。风险、总仓位和集中度超限由收盘持仓、当步协方差与存档上限重算，区分账户 × 步和不同步骤数，并可跳到首个超限步骤。账本守恒不代表风险始终合规。

“调整策略再跑”复制配置生成另一份实验。比较页先列原文、分析、情景、种子、初始资源及机制标识的差异，再比较参数和结果；条件不同仅作描述性比较。选择、回放和打开账本都使用比较时捕获的版本。

报告提供 Markdown、离线 HTML、指标与完整快照 JSON，以及服务器原始双实验 JSON。页面报告固定于读取的快照；服务器下载核对左右结果版本，重跑或运行中发生冲突时拒绝下载另一版账本。

## 批量与归档案例

“批量对照”将多个种子与四种固定情景组合，每个种子共用无消息基线。单项失败后继续后续项，重试只运行未完成项。汇总显示覆盖、失败、各角色均值和最小最大范围，所有项完成后才称批次完成。范围为种子敏感性，不是置信区间。本入口不调用模型。

“真实原文案例”读取六个开发案例：资管政策答记者问、武汉交通通告、春节休市公告及三条公司回复。条件包括无文本、关键词、复核后 LLM 和资产暴露置换。页面分开原始模型事实、助手修订、数值映射与市场路径，可定位引文并导出。

“历史行情实验”读取真实回复与历史收益的单案例三条件回放。价格为外生历史收益，成交为简化指数单位；未模拟盘口、滑点或市场冲击。实验保留负结果，不能证明策略普遍有效。

两个归档入口只读，均不重新调用模型或仿真。缺少本地归档会明确提示，不用模板代替结果。

## 文本分析与模型设置

后端从 `.env.local` 或环境变量读取 `MARKETMIRROR_LLM_API_KEY`，模型与网关配置见[首页](../README.md#文本分析配置)。打开模型设置只读取配置；“检测连接”发送固定合成文字，记录耗时与结果，不发送草稿、不创建实验或分析。

提取事实时保存原文、事实、唯一逐字引文及位置、模型、提示词版本与哈希、原始响应及时间。创建和运行实验均核对完整快照，事实数组为空仍可形成有效分析。引用匹配只证明引文来自原文，语义判断需逐条复核。

模型失败区分凭据、限流、超时、网络、网关及结构问题；失败分析不保存。连接检测结果存在服务内存，重启或凭据改变后失效；通过仅表示请求与结构校验成功。

## 存储与接口

数据根目录为 `research_outputs/platform_workspace/`。成功运行先写 `runs/<result_id>.json`，再原子发布结果指针与状态；失败保留上一次成功版本。服务工作区由独占租约保护，启动恢复未结束运行为中断状态。此机制保证应用层一致性，不承诺断电持久性。

接口前缀为 `/api/platform`，请求使用 JSON：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /health` | 服务状态 |
| `GET/POST /strategies` | 读取或保存工作区默认参数 |
| `POST /strategy-preview` | 用 `parameters` 与 `scenario` 计算六份同状态决策 |
| `GET /model`、`POST /model/check` | 配置及固定合成文字检测；检测只接受空对象 |
| `POST /analyze`、`GET /analyses/{id}` | 提取事实、核验并读取已存分析 |
| `GET/POST /experiments` | 列出或创建实验；创建支持 `Idempotency-Key` |
| `GET /experiments/{id}`、`POST /experiments/{id}/run` | 读取配置、运行市场 |
| `GET /experiments/{id}/result`、`GET /experiments/{id}/export` | 读取结果或下载完整归档 |
| `GET/POST /batches`、`POST /batches/{id}/run` | 列出、创建和启动批量情景 |
| `GET /batches/{id}`、`GET /batches/{id}/export` | 批次进度及归档 |
| `GET /source-cases`、`GET /source-cases/{id}`、`GET /source-cases/{id}/export` | 原文案例目录、所选条件与导出 |
| `GET /observed-experiments`、`GET /observed-experiments/{id}`、`GET /observed-experiments/{id}/export` | 历史行情实验与导出 |
| `GET /comparisons/{left_id}/{right_id}/export` | 核对所选版本并下载双实验原始快照 |
