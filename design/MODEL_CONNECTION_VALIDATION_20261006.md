# 模型设置与实际连接核验

2026-10-06。平台的模型设置从后端读取实际模型、网关、事实提取规则和本机凭据状态，提供明确触发的连接检测。指定模型保持 `DeepSeek-V4-Flash-0731-W8A8`，不改动原研究协议、语义门槛或已保存的市场路径。

## 行为与边界

- `GET /api/platform/model` 只读本机配置，不发送模型请求。密钥和内部配置指纹不返回浏览器、不写入检测记录。
- `POST /api/platform/model/check` 只接受 `{}`；沿用生产入口的提示词、请求和逐字引文校验，仅发送固定合成文字：“连接检测用合成文字：示例公司的新建生产线仍在办理审批，尚未取得正式批复，具体投产时间不确定。”
- 检测不使用草稿、真实研究样本、财务字段或复核标签，不创建分析或实验。模型仍可能返回错误事实，结构通过不等于语义正确。
- 服务拒绝同时检测；读取状态仍可使用。关闭窗口不会中断已发出的请求，迟到结果不会改写其他弹窗；响应丢失时提示未确认，可刷新读取服务端结果。
- 最近结果只保存在内存，服务重启后清除；凭据改变时旧结果失效。检测过程中配置改变不能认证新配置。零事实属于有效返回，不强制模型生成事件。
- 生产文本提取与检测均区分鉴权、限流、超时、网络、网关、请求拒绝和内容不合格；错误使用固定安全说明，不转发网关正文。失败分析不落盘。
