# 已保存实验比较与策略调整核验

日期：2026-10-07。范围：两份合成市场实验的读取、条件核对、参数调整、收益及订单比较和完整账本版本。

## 实现

- 新增“实验比较”页面，左右选择两份完成且审计通过的 `synthetic_market` 实验。使用既有导出接口取得配置和结果的同一快照，不拼接两次独立读取。
- 重新计算原文 UTF-8 SHA-256，核对实验／结果绑定、参数及机制标识、逐步决策和信息输入。期末现金加持仓市值必须等于保存的净资产，订单数量必须完整且与汇总一致。
- 固定输入条件和可调策略参数分别核对。种子、原文、分析依据、市场偏移、波动率、时长、资金或固定参与者条件不同，明确列出差异，不显示成单纯参数效果。
- 全程指标由两份实际账本计算，涵盖全部资产的买卖请求、接受和成交。收益按每类账户的期末／初始净资产合计计算。同一步目标和分值沿用决策前净资产加权。
- 改变选择立即使旧比较失效。迟到的成功或失败不会覆盖新选择；空值或越界步数保留最后有效数据，不转成第 0 步。输入多位步数只更新标题与卡片，不替换正在编辑的输入框。
- 完整账本打开比较捕获的 `result_id`。页面说明快照来源，提供返回比较按钮；导出仍用该版本。所选编号在当前标签页保存，刷新后重新核对。点击“刷新所选版本”才主动刷新当前比较快照。
- “调整策略再跑”复制原文、情景、种子、市场假设、参数和参考，进入独立草稿的第二步。新实验须正常确认运行，已有实验保持原值。

本功能没有新增仿真或 LLM 算法。DeepSeek 负责原文事实提取；三类角色的规则和撮合机制保持原实现。
