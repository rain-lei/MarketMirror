# 回放控件改进与核验

2026-10-08。针对步数滑块不直观的问题，改进普通结果、真实原文案例和历史行情实验共用的回放控件。

## 改动

- 合并之前分散的轨道、原生滑块和移动样式，消除互相覆盖的尺寸与位置定义。轨道与滑块使用同一个容器，当前步气泡在起点和终点向内对齐。
- 突出显示当前步数／总步数及归档日期，保留消息进入标记、作用区间、逐步数字按钮和状态说明。将“当前进度／定位百分比”改成明确的“当前回放”，避免误解为任务运行进度。
- 增加步数输入与跳转按钮。点击跳转或按 Enter 提交；空值、越界、小数和非数值提示错误，保持原决策步；Escape 恢复当前回放位置。
- 拖动、刻度、前后步、消息进入和精确跳转均分发同一个 range 输入事件，继续更新当前页的日期、决策与图形。移动布局允许数字步骤横向滚动、操作按钮换行。

## Agent 模型核对

三个 Agent 是本地参数化规则引擎的三种配置，没有分别训练三套投资者模型。激进型响应更快；保守型对不确定性更敏感并使用连续确认；机构型使用再平衡周期和三资产集中度约束。规则同时记录市场、文本与不确定性贡献、目标仓位、订单和成交。

DeepSeek-V4-Flash-0731-W8A8 是共享的原文事实提取模型。新建情景的方向与不确定性由用户设置，归档案例使用登记映射。市场每步不调用大模型。现有策略页和结果页中的模型说明与这一实现一致。
