# 实验风险比较与导出版本核验

2026-10-08。此前实验比较页和报告只比较收益、订单数量及同一步目标仓位，难以判断调整参数之后的费用、回撤和未成交风险。本轮将已有账本风险指标接入比较及导出，并防止原始下载读取另一版运行结果。

## 指标与交互

比较页每类策略增加最大回撤、订单费用、成交／请求比例、风险／总仓位超限和单资产集中度超限。计算复用 `portfolio-metrics.js`，只读取两份保存的完整账本。

回撤按整类账户初始净资产与各步收盘净资产合计计算，包含初始库存；费用只统计该角色订单。没有请求时显示“未下单”，缺失风险或费用字段则保留未知及具体原因。超限同时列出账户×步和受影响步数，差值按各自的账户×步比例计算为百分点，允许时长不同的描述性比较。费用差值为模型元，其余比例差值标明 pp。

首个超限链接打开对应实验的原结果版本、信息条件和决策步，保留资产。该步可以超出两份实验共有的并列窗口，但不会改写比较页的查看位置。非法步骤、信息条件或非所选实验编号不触发导航。

## 报告与版本

- 页面、Markdown 和 HTML 报告使用相同的风险指标与单位。比较 JSON 采用 `platform-comparison-v2`，报告结构为 `platform-comparison-report-v2`；保存两份完整实验、指标、超限账户、来源及结果编号。
- 报告从完整账本重算指标，拒绝被改写的费用、回撤、超限计数或单位。旧 v1 比较快照缺少风险汇总时从原账本重建；已有但不一致的风险汇总不能通过。
- 导出准备期间改变页面选择，不会把新实验混入已捕获的报告或 JSON。
- 服务器原始下载带 `left_result_id` 和 `right_result_id`。左右版本与已完成状态、结果内来源绑定都必须一致。重跑、运行中或结果绑定损坏时返回 HTTP 409，提示刷新比较；重复、空值、不完整和未知查询条件返回 HTTP 400。下载不触发市场运行。

## 实际运行的人工压力情景

在独立验证目录中，使用此前已运行的人工高波动压力情景作为基准，只将保守型风险预算从 0.008 调整为 0.004，实际完成一次新的 18 步、两条件撮合运行。原文、信号 −0.6、不确定性 0.8、持续 6 步、种子 7、市场偏移 −0.2、波动下限 0.1、资金和其他参数一致。

基准实验为 `3a579be2f9ae4a33a596d62ac902f2cd`，结果为 `c3b46f6161804263af1f6a220aea79ca`。调整后实验为 `0a8a3a467d104ca5ad4bccb640e5c733`，结果为 `d58382861dfd42858491e11b667a3f70`。两份实验各运行 1 次、审计 36 个市场日，共 72 日；没有调用 LLM，没有加入主工作区的用户实验列表。
