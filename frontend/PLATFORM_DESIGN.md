# MarketMirror 企业平台设计说明

## 1. 设计目标
- 将监管沙盒从单页演示升级为企业级控制台
- 支持账号登录、模块化导航、审计留痕与运行配置
- 保持前后端边界清晰，便于接入真实认证与风险引擎

## 2. 分层架构
1. 表现层
- `index.html`：平台骨架与模块容器
- `src/styles/app.css`：设计系统、布局、状态样式

2. 应用层
- `src/App.vue`：平台状态、登录流程、模块切换、推演编排

3. 服务层
- `src/services/api.js`：后端请求统一入口（含超时与错误处理）
- `src/services/auth.js`：前端演示鉴权与会话管理

## 3. 模块职责
- 登录层：账号密码校验、会话持久化
- 场景推演：输入冲击事件，调用 `/api/simulate`，展示 Agent 结果
- 风险预警：展示系统风险评分与风险等级（可扩展真实指标）
- 审计中心：展示操作日志（后续可接 API）
- 平台配置：展示环境与接口地址

## 4. 安全与合规建议
- 用后端 JWT / OAuth2 替换前端账号表
- 所有敏感接口增加鉴权、审计、速率限制
- 接入 SIEM 或日志平台，支持事件追溯

## 5. GitHub 协作建议
- PR 前执行静态检查与接口联调
- 约定提交信息前缀（feat/fix/docs/refactor）
- 通过 CODEOWNERS 管理评审责任
